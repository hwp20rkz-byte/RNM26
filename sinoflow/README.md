# SinoFlow AI

Интерактивный прототип B2B SaaS для агентов по закупкам в Китае: заявка → 4 ИИ-агента → переговоры в WeChat/WhatsApp → стоимость до двери в ₽ ₸ ¥ $. Внутри два режима (кабинет и презентация из 8 слайдов) и озвученный гид на Web Speech API.

```bash
npm install
npm run dev        # http://localhost:3300
npm test           # валютный движок, прайсинг, landed cost, прогон воркфлоу
npm run build      # статический экспорт в out/
```

После слияния в `main` GitHub Pages публикует приложение по адресу `/RNM26/sinoflow/`.

## Структура

| Путь | Что внутри |
|---|---|
| `src/types/sourcing.ts` | Строгие типы: заявка, агенты, поставщики, котировки, сообщения, курсы ₽ ₸ ¥ $ |
| `src/lib/currencyEngine.ts` | Курсы ЦБ РФ (кросс-курсы KZT и CNY через USD), конвертация, FX-спред, коммерческое округление, прайсинг услуг, стоимость до двери |
| `src/lib/catalog.ts` | Каталог услуг, описания агентов, логистические профили Алматы / Москва / Екатеринбург |
| `src/lib/mockAgentWorkflow.ts` | Демо-кейс VMC-850 и машина состояний 4 агентов с паузой, перемоткой и подтверждением оператора |
| `src/lib/tourScript.ts` | 12 шагов гида: тексты RU/EN и действия над интерфейсом |
| `src/components/NarratedDemoPlayer.tsx` | Плеер гида: озвучка по предложениям, пауза, перемотка, прогресс, субтитры при отсутствии голоса |
| `src/components/PitchDeck.tsx` | 8 слайдов, юнит-экономика считается вживую |
| `src/components/Dashboard/*` | Форма заявки с расчётом услуг, визуализатор агентов, ТЗ и RFQ, сравнение поставщиков, мессенджер, стоимость до двери |
| `backend_blueprint/` | FastAPI + LangGraph + PostgreSQL + Valkey + Crawl4AI, с тестами (см. его README) |

## Что в прототипе симуляция

- Поиск, переписка и ответы заводов — демо-данные; названия заводов вымышлены.
- Курсы берутся вживую с зеркала ЦБ РФ (`cbr-xml-daily.ru`); если оно недоступно, интерфейс показывает «снимок».
- Ставки НДС (РК 16%, РФ 22%) и пошлины — параметры профиля; перед реальным КП их сверяет брокер.
- Озвучка зависит от голосов в системе. Если голоса RU нет, гид идёт по субтитрам с той же синхронизацией.
