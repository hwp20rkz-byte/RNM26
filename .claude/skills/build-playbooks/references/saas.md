# Playbook: SaaS Landing Page

Conversion-focused, integration-heavy. Target: 3–8% visitor→trial conversion.

## What the founder actually needs
- Hero that converts; value proposition in ~6 words
- 3–5 features explained visually
- Pricing table that doesn't confuse
- Social proof: logos, testimonials, metrics
- Stripe Checkout / Paddle; analytics + A/B baked in
- CMS for blog + changelog

## Phase plan (7 phases)
1. Brief: palette/type; hero headline LOCKED before building
2. Hero + features: product mock or demo loop; 3–5 feature sections static
3. Social proof + pricing: logos, testimonials, metrics; 3-tier table
4. Integrations: Stripe Checkout, Resend waitlist, Plausible, welcome email sequence
5. Motion + polish: subtle scroll animations, hover micro-interactions, checklist
6. Blog + CMS: Sanity or MDX, 1 launch post, changelog page
7. Launch: domain, Lighthouse 95+, og:image (optionally Product Hunt assets)

## Hero structure that converts (in order, top to bottom)
1. Eyebrow category tag ("AI design tool" / "For founders")
2. Headline 6–10 words, specific outcome
3. Subhead 15–25 words: who, what, why now
4. Primary CTA ("Start free trial") + secondary CTA ("See how it works")
5. Visual: product screenshot or 30-second loop
6. Social proof bar: "Trusted by N+ teams" + logos

## Pricing table rules
- Exactly 3 tiers; middle tier highlighted "Most popular"
- Annual toggle with savings (~20%)
- Feature comparison below only if complex
- FAQs immediately after pricing — they handle objections (trial length, cancellation, integrations, security, seats, refunds, custom plans, support)

## Copy generation patterns
- Hero variants ×5 from product + 1-sentence what-it-does + customer + pain. Vary angle: specific number / outcome promise / contrarian claim / before-after / metaphor. Recommend which to A/B test first.
- Pricing copy: tier names, prices, toggle text, 5–7 features each, CTAs, + 8 objection-handling FAQs.
