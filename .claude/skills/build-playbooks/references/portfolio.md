# Playbook: Personal Portfolio

Fastest archetype. Goal: "I am serious" in 3 seconds.

## What the client actually needs
- 3–8 work pieces, big visuals
- About paragraph that doesn't bore
- Contact (email or form)
- Often a small CMS so they add work themselves

## Phase plan
1. Brief: hero concept (often big type), palette+type, wireframe, 3–5 work pieces selected
2. Skeleton + content: all sections static, work uploaded
3. Motion: hover effects on work grid, page transitions, smooth scroll
4. Polish + optional Sanity for work pieces; polish checklist
5. Launch: domain, Lighthouse

## Hero patterns that work for portfolios (pick one)
- Big type + reveal + work grid below (default)
- Single image + name + 1-line bio
- Vertical scroller of work, no traditional sections
- Editorial-magazine layout with table of contents
- 3D rotating object + name + click-to-explore

## Work piece presentation
- Grid preview; hover loads short video or hi-res image
- Click → detail page or modal
- Detail page: big image → 2–3 context paragraphs → 5–8 supporting images → related works
- Fast prev/next navigation between works

## About copy pattern
From profession + 3-word style + years + target industry → 3 voices (confident-understated / warm-story-led / provocative-manifesto), 3 short paragraphs each, with a recommendation. Voice must stay consistent with the motion personality of the site.
