# Playbook: Agency / Studio

The heaviest archetype: cinematic, motion-led, award-grade. The site must prove the studio can do for clients what it does for itself.

## What the client actually needs
- ONE cinematic hero centerpiece (3D, shader, or video — never stacked effects)
- 3–6 case studies with "making of" depth
- Team section with personality (no stock photos)
- Clear "work with us" funnel
- Awwwards-grade polish throughout

## Phase plan (7 phases — this archetype earns the extra two)
1. Brief: palette, typography, brand voice locked; wireframe
2. **Hero centerpiece** — R3F scene / shader / hero video, built and optimized FIRST (it's the risk item)
3. Skeleton + Lenis smooth scroll, all sections, preview deploy
4. Case studies: 3–6 from the template below; pinned scroll-y treatment
5. Motion polish: GSAP timelines, Framer micro-interactions, hover states
6. Performance + a11y: code-split, image work, Lighthouse 90+, reduced motion
7. Launch + (optionally) award submission

## Hero rules
- ONE signature moment; options: R3F scene + scroll camera, GLSL shader, looping video, masked GSAP type-in
- ≤1MB after compression
- Static fallback for reduced-motion; simplified mobile version mandatory

## Case study template (converts)
1. Cover: single hero image + project name
2. Brief: 2–3 lines — who, what, why
3. Process: 3–5 short sections with images
4. Result: ONE sentence with a metric
5. "Visit live" button
6. 3–4 related-work thumbnails

## Copy generation patterns
- Hero copy in 3 voices (bold-provocative / elegant-restrained / playful-confident): headline ≤8 words, subhead ≤15, CTA label; then recommend the fit.
- Case study skeleton from 5 sentences about a project: tagline (8 words), brief, 4 process sections (header + 2 lines + suggested image type), metric result, placeholder quotes. Tone: confident, plain, zero agency-speak.
