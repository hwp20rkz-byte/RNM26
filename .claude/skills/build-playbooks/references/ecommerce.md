# Playbook: E-commerce

The heaviest and most lucrative archetype. First decision gates everything.

## Path decision (make BEFORE any work)
| Path | When |
|---|---|
| **Shopify** (Hydrogen / Storefront API) | 50+ SKUs, multi-currency, fulfilment complexity |
| **Custom** (Next.js + Sanity products + Stripe Checkout + Resend) | boutique brand, 5–30 SKUs, single region, editorial/cinematic feel Shopify can't do; fully owned, faster for small catalogs |

## Phase plan (10 phases, Shopify variant; custom path compresses to ~7)
1. Brief: brand, products, currencies, regions, payment methods locked
2. Hero + brand storytelling section
3. Product templates: cards, detail page, gallery, variants, sizing
4. Collections: pages, filters, sort, search
5. Cart + checkout: cart drawer, mini-cart, hosted-checkout customization
6. Account + post-purchase: order history, returns flow
7. Content: blog/lookbook, SEO content
8. Integrations: email flows (Klaviyo-class), support, reviews, analytics
9. Performance + a11y: Lighthouse 90+/80+, accessible forms
10. Launch: domain, ALL payment flows tested with a real low-value transaction, 30-day care plan

## Conversion patterns every store needs
- Trust badges near checkout (secure payment, free returns, reviews)
- Cart-abandonment email flow: 3 emails at 1h / 24h / 72h
- "Frequently bought together" cross-sell in cart drawer
- Free-shipping threshold progress visible in cart
- Live stock scarcity on product page ("only 3 left") — only if true
- Estimated delivery date from user location
- Reviews on product card AND product detail page

## Email flows to set up
Welcome, abandoned cart, post-purchase, win-back.

## Image strategy
- ≥3 angles per product + lifestyle context; hero per category
- AI imagery for lifestyle/mood ONLY — never for product shots presented as real
- Same compression discipline as everywhere: AVIF, width/height set

## Brief generation pattern
From brand, products, catalog size, customer, currencies, markets → output: Shopify-vs-custom recommendation (3 lines), sitemap with page types, hero copy ×3 voices, collection naming, email flow list, 5 highest-leverage conversion optimizations specific to this brand.
