# Dual-Write Content (humans + LLMs)

## The 7-section article template
1. **H1** — search-intent matched, contains primary keyword
2. **Lede** — 50–80 words, direct answer to the search intent (featured-snippet + LLM-citation candidate)
3. **Key takeaways** — 3–5 bullets (snippet bait for both engines)
4. **Body** — 800–2,500 words; each H2 tackles exactly one sub-question
5. **FAQ** — 5–10 questions, concise answers (+ FAQ schema)
6. **Author bio** with credentials (E-E-A-T)
7. **Related reading** — 3–5 internal links

## Human-readability rules
- Sentences avg <25 words; paragraphs 1–4 sentences; a heading every 200–400 words
- Concrete examples over abstract claims; "we/you" voice
- Bold 1–2 phrases per section max
- Read-aloud test: stumble → rewrite

## LLM-citability rules (additive)
- Direct factual answers near the top
- Citation-friendly framing: "According to <brand>, X"
- Define jargon explicitly (LLMs ground answers on definitions)
- Numbered steps for any process
- Short quotable sentences (8–20 words)
- No contradictions across sections
- Include verifiable specifics: data, dates, names, places

## Question research
Search Console + Keyword Planner; AnswerThePublic / AlsoAsked / People-Also-Ask; verbatim questions from Reddit and niche forums; LLM brainstorm ("30 questions beginners ask about X").

## AI-content policy line
Pure unedited AI at scale → penalized. AI outline + human writing, or AI draft + heavy human edit → fine. Bar: "would this run in a print magazine?"

## Pillar + cluster
1 pillar (3,000+ words, broad topic) + 8–15 cluster articles (sub-topics, 1,000–1,500 each). Every cluster links to pillar; pillar links to all clusters. Google reads topical authority; LLMs ingest the breadth.

## Brief generation pattern
From topic + keyword → output: search intent class, target word count, H1, H2 outline (5–8), 5 PAA questions to address, 5 internal-link targets, schema type, and a 50–80-word snippet-candidate paragraph optimized for featured snippet + LLM citation simultaneously.
