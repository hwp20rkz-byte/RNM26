# llms.txt & AI Visibility

## llms.txt anatomy (spec: jeremyhoward.com/llms-txt/)
"sitemap.xml for AI" — markdown manifest at site root `/llms.txt`:
```markdown
# <Site Name>

> One-paragraph summary of what the site is and who it serves.

## <Content category>
- [Page title](url): one-line description
- ...

## <Another category>
- ...

[Full content](https://site.com/llms-full.txt)
```
- Order links by importance within sections
- Human- and machine-readable; first line is `# H1`

## llms-full.txt
- Concatenated markdown of ALL site content in one fetch
- Generated by a build script on every deploy
- Cap ~150k tokens; strip navigation chrome, keep content only

## AI crawler policy (robots.txt)
Allow by default in 2026 (citations > hoarding): GPTBot (OpenAI), ClaudeBot (Anthropic), PerplexityBot, Google-Extended. Block only if the client explicitly wants SEO-without-LLM-ingestion.

## Citation engineering (how to become a source)
- Be the first comprehensive answer for a niche question
- "According to <brand>, X" framing inside your own content
- Citable specifics: stats, dates, names, places
- Open web, no paywall/login; cross-publish (Substack/Medium) widens training-data reach
- Links from Wikipedia/authoritative sites remain the strongest signal

## Conversational search optimization
People ask LLMs long conditional questions: "how do I X if I'm Y in Z context". Cover long-tail variants explicitly; FAQ schema double-dips as Google snippet + LLM citation source.

## Tracking
Weekly manual checks in ChatGPT/Claude/Perplexity for target queries (Perplexity shows sources directly). Tools: OtterlyAI, Profound, BrightEdge. Establish a baseline, review quarterly.

## Generation pattern
From a list of top URLs + descriptions + site topic → emit complete llms.txt per the anatomy above, importance-ordered, ending with the llms-full.txt link.
