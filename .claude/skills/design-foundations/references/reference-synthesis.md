# Reference Synthesis — steal structure, not style

Senior output doesn't start from a blank canvas; it starts from 30–50 curated references synthesized into a structural plan. Fresh-looking results come from synthesizing many sources, never copying one.

## The core law
**Steal structure, style is generated fresh.**
- Structure = section order, typographic hierarchy rhythm, spacing cadence, layout patterns ("video hero → 3-col grid → side-scroll case studies → tall-type footer")
- Style = colors, typefaces, photography, copy voice — always original per brief

## Tagging model (for any stored reference library)
type (hero/footer/gallery/form) × industry × vibe (cinematic/brutalist/minimal/playful) × tech (gsap/scroll-driven/3d) + a one-line "what's interesting / what to steal" note.

## Synthesis pattern (run on Phase 0/2 of a build)
Input: 30 one-line structural notes on references relevant to the brief.
Output:
1. The dominant structural pattern across them
2. The 3 most interesting outliers
3. Recommended section-by-section structure for the new site
4. Explicit list of what NOT to copy stylistically

## Agent adaptation
When no human-curated library exists, derive structural notes from the playbook archetypes + known pattern languages (the 7 layouts in layout.md), and document which structures were borrowed in the build plan. Never reproduce a single reference site's identity.
