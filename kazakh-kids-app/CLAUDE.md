# CLAUDE.md — QazaqVerse: Tíl Quest (kazakh-kids-app/)

Манифест разработки игры. Загружается Claude Code при работе в этой папке. Планы: `methodology/master-plan-30.md`
(30 дней, текущий), `methodology/dev-plan.md` (журнал), `methodology/plan-10-days.md` (фаза 2 «Мектеп»).

## 1. Инварианты платформы и сборки
- Offline-first игра для Android 5.0+ (WebView). Новая версия ставится поверх старой: уроки, монеты, герои и наклейки
  сохраняются (`localStorage` ключ `qazaqsha-oyna-v1`, миграции только добавляют поля).
- Две цели сборки: боевая `QazaqVerse` (`./build.sh`) и тестовая `Test QazaqVerse` (`TEST=1 ./build.sh`, отдельный
  пакет, все уроки открыты, 99 сердец, кнопка ⏭ TEST, «Дауыс зертханасы»).
- **APK собирается только по прямой команде владельца** (`/build-dual-apk`). Без команды — сообщить «готов к сборке».
- Бюджет APK: ≤ 75 МБ (сейчас ~45 МБ). Аудио — mp3 32 кбит/с моно. Переход на Opus — только после проверки
  воспроизведения на реальном Android 5–7 (поддержка Ogg Opus в старых WebView не гарантирована).
- 3D-зал (`suite/`): бюджет JS 4,2 МБ / 1,45 МБ gzip (`npm run budget`).

## 2. Морфологический движок — TDD обязателен
- Запрещено вписывать словоформы вручную в таблицы уроков и карточек: все формы строит `web/grammar-core.js`
  (сингармонизм, озвончение п/к/қ → б/г/ғ перед гласной, беглые гласные ауыз → аузым, мұрын → мұрны,
  -быз после м/н/ң, повелительное наклонение, «могу», числа и падежи). В 3D-зал формы попадают через генератор
  (`tools/build-lego.js` → `suite/src/data/legoForms.ts`) или сверку корпуса с движком в тестах.
- Новое правило: **сначала** эталонные проверки в `tests/grammar.test.js` (формы пишет человек/методист),
  потом код. Перед коммитом — `npm test`: 100% зелёных (сейчас 1703 проверки).

## 3. Голоса и проверка распознаванием (ASR)
| Слой | Что | Где |
|---|---|---|
| Диктор офлайн | ISEKE (Piper), все фразы диктора | `web/audio-iseke/` |
| Второй диктор | «Томирис», Freedom Speech | `web/audio-tomiris/` (+ `skip.json`) |
| Герои (12) | каталог Freedom Speech, подбор по высоте | `tools/voice_studio/fs-cast.json` → `web/audio/` |
| Детские голоса (план) | OmniVoice (Hugging Face) | `tools/voice-studio.py` |
- **ISSAI выведен 13.11.2026 по решению владельца.** Резерв для испорченной фразы — ISEKE (не ISSAI).
- Каждая новая реплика проходит ASR-проверку (`--verify`); фраза, которую модель портит стабильно (например,
  проглоченное местоимение «Мен/Сен/Сіз»), уходит в `web/audio-<пакет>/skip.json`. Отдельно проверять начало фразы:
  порог похожести 0,80 не ловит потерю короткого слова в длинной фразе.

## 4. Секреты
- Ключи (`FS_API_KEY`, `HF_TOKEN`) — только переменные окружения или локальный `.env` (в `.gitignore`;
  шаблон — `.env.example`). Никогда не писать ключ в файлы, коммиты, логи и временные скрипты.
- Хук `.githooks/pre-commit` (включается `git config core.hooksPath .githooks`) и job `secrets` в CI (gitleaks)
  блокируют коммит с секретом. Перед коммитом — `tools/scan-secrets.sh`.

## 5. Авторское право и факты
- Материалы kaz-tili.kz, учебников и других ресурсов не копируются: только темы; тексты и примеры — свои.
  Литература — только общественное достояние (Абай, Ыбырай Алтынсарин, Ахмет Байтұрсынұлы, фольклор).
- Голоса реальных актёров и узнаваемых персонажей фильмов, игр, мультфильмов не имитируются — только типажи.
- История, география, достопримечательности: у каждой карточки источник в методичке; спорное — не для 1–5 классов.

## 6. Готово = (Definition of Done)
Тесты (`npm test`, `cd suite && npx vitest run`, сквозные `tests/*.e2e.*`, `suite/tests/e2e/*`) зелёные; скриншоты
телефона 400×860 и десктопа просмотрены глазами; озвучка новых фраз; запись в журнале `methodology/dev-plan.md`
и методичка `methodology/games-in-class.md`; коммит и push в ветку разработки.
