# Игры QazaqVerse на уроке — методические заметки для учителя

Пополняется после каждого спринта. Для каждой игры: цель, класс, как провести 5–10 минут на уроке, типичные ошибки.

## «Сөйлем экспресі» (3D-зал «Неостепь») — порядок слов

**Цель.** Ученик ставит слова в казахском порядке: подлежащее → (время) → (место) → дополнение → **сказуемое в конце**.
Отличает команду (бұйрық рай: *аш!*, *ашыңыз!*) от формы настоящего-будущего времени (*ашамын*, *ашады*).

**Класс.** 1–2 класс — режим «Кім? Не? Не істейді?» (3 слова). 2–3 класс — «Қашан? Қайда?» (3–5 слов, время и место).
Любой класс — «Бұйрық» (команды учителя и врача).

**Как провести (7 минут).**
1. На доске: *Мен кітап оқимын.* Спросить: где стоит глагол? (в конце). Сравнить с русским «Я читаю книгу».
2. Один раунд (6 предложений) на интерактивной доске или телефоне: класс подсказывает, ученик у доски нажимает капсулы.
3. После каждого «отправления» экспресса — повторить предложение хором (оно звучит из игры).
4. Режим «Бұйрық»: учитель говорит команду (*Кітабыңды аш! Тақтаға шық!*), класс выполняет; затем то же предложение
   собирают в игре. Ловушка (*ашамын*) — повод объяснить: команда — это основа глагола; вежливо — *-ыңыз / -іңіз*.

**Типичные ошибки и что сказать.**
| Ошибка | Подсказка в игре | Что сказать |
|---|---|---|
| Глагол первым (*барамын мектепке*) | «Глагол всегда в конце» | В казахском действие — последнее слово. |
| Место после глагола | «Кто → когда → где → действие» | «Где?» стоит прямо перед глаголом. |
| *ашамын* вместо *аш* в команде | «не команда; команда — основа глагола» | *ашамын* — «я открываю»; приказ — *аш!*, вежливо *ашыңыз!* |

**Допустимые варианты.** Игра принимает и *Ертең біз саябаққа барамыз*, и *Біз ертең саябаққа барамыз* — время может
стоять первым. Ученика, выбравшего такой порядок, не исправлять.

**Связь с программой.** Порядок слов — карточка «Сөз тәртібі» в разделе «Сөздік → Грамматика»; команды врача —
по мотивам разговорника «Денсаулық» (см. `tilashar-notes.md`), примеры свои.
