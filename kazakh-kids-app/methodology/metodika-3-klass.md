# Интерактивные уроки казахского языка, 3 класс
## Методические разработки к треку «Оқулық» приложения QazaqVerse: Tíl Quest

**УМК:** «Қазақ тілі», 3 класс, для школ с неказахским языком обучения (модули 1 «Жанды табиғат», 2 «Жақсыдан үйрен, жаманнан жирен», 3 «Уақыт», 4 «Сәулет өнері»). Модуль 2 в материалах предоставлен до стр. 53 (уроки 1–5, урок 5 — частично); стр. 54–73 не включены.

**Для кого:** учитель казахского языка в 3 классе, родитель, ученик, занимающийся самостоятельно.

**Как устроено пособие:** у каждого урока учебника есть «зеркальный» урок в приложении (трек «Оқулық») и тематическая игра для закрепления. Ниже — общая методическая часть, затем поурочные разработки (40 минут) с привязкой к заданиям учебника, интерактиву приложения, дифференциации и дескрипторам, затем суммативное оценивание за раздел (СОР) по каждому модулю.

## 1. Общая методическая часть

### 1.1. Принципы
- **Коммуникативность.** Каждое правило «Тілдік бағдар» сразу работает в речи: образец → тренировка в приложении → собственное высказывание.
- **Четыре вида речевой деятельности.** Тыңдалым (аудирование), Оқылым (чтение), Айтылым (говорение), Жазылым (письмо) — в каждом уроке; в приложении задания размечены по навыкам, и итоговый результат показывается по каждому навыку отдельно.
- **Спиральность.** Лексика урока повторяется в тематической игре и затем в итоговом уроке модуля (повтор через 1–2 недели).
- **Дифференциация ★ / ★★ / ★★★** — как в учебнике: ★ все ученики, ★★ большинство, ★★★ некоторые (задания повышенной сложности).
- **Игра — после понимания, а не вместо него.** Тематическая игра открывается в приложении только после прохождения урока: она закрепляет, а не вводит материал.

### 1.2. Структура урока (40 минут)

| Этап | Время | Что происходит | Где |
|---|---|---|---|
| 1. Организационный момент, «Ой қозғау» | 2 мин | Приветствие, настрой, тема урока по картинке учебника | класс |
| 2. Проверка домашнего задания | 4 мин | Взаимопроверка в парах, 2–3 ответа вслух | класс |
| 3. Новая лексика | 7 мин | Карточки слов с озвучкой, хоровое и индивидуальное проговаривание | приложение: «Изучи слова» |
| 4. Грамматика «Тілдік бағдар» | 6 мин | Правило на примерах, наблюдение, вывод | учебник + подсказка в приложении |
| 5. Тыңдалым и оқылым | 8 мин | Аудиотекст (QR в учебнике), текст для чтения, вопросы | учебник |
| 6. Айтылым | 5 мин | Диалог, ролевая игра, интервью в парах/группах | класс |
| 7. Жазылым | 4 мин | Письменное задание учебника | тетрадь |
| 8. Закрепление | 3 мин | Урок в приложении (5–7 мин дома) + тематическая игра | приложение |
| 9. Рефлексия и оценивание | 1 мин | «Бағдаршам» (светофор), самооценка по дескрипторам | класс |

> Если в классе нет устройств для каждого ученика, этап 8 проводится фронтально на проекторе (класс отвечает хором, к экрану выходят по одному), а полный урок в приложении задаётся на дом.

### 1.3. Система оценивания
**Формативное оценивание (ФО)** — на каждом уроке, без отметки: дескрипторы (см. поурочные разработки), «Бағдаршам», «Две звезды и одно пожелание», а также автоматический результат приложения: процент заданий, выполненных **с первой попытки**.

**Суммативное оценивание за раздел (СОР)** — итоговый урок модуля: тест в приложении (14 заданий по четырём навыкам) + устная и письменная часть по учебнику (раздел 4 пособия).

**Перевод процентов в отметку** (так считает и приложение):

| Процент | Отметка | Уровень |
|---|---|---|
| 85–100 % | «5» | высокий |
| 65–84 % | «4» | достаточный |
| 40–64 % | «3» | средний |
| 0–39 % | «2» | нужна поддержка |

**Где учитель видит результаты:** Профиль → «Мұғалім парағы · для учителя». Там по каждому итоговому уроку — дата, процент, отметка и разбивка по навыкам (Тыңдалым, Оқылым, Жазылым, Айтылым), а по каждой тематической игре — лучший результат.

### 1.4. Голос
По умолчанию слова и фразы уроков озвучиваются голосом **ISEKE** (Профиль → Голос). Альтернатива — **ISSAI**: по нашему автоматическому тесту распознаваемости он чётче (ISSAI ≈ 60 %, ISEKE ≈ 49 % фраз распознаны без ошибок). Для слабых учеников и первичного знакомства со звуками рекомендуем ISSAI; ISEKE — для разнообразия тембра. Реплики персонажей игр всегда звучат голосами ISSAI.

### СОР № 4. «Сәулет өнері»

**Цели обучения:** находить слова темы и употреблять их в речи; описывать здания (сырты, төбесі, неден жасалған); употреблять падежи и септеулік шылаулар. Часть А — чекпоинт в приложении: 5 минут, 3 ❤️; затем «Тіл Кереметі».

| № | Навык | Задание (часть Б) | Дескриптор | Балл |
|---|---|---|---|---|
| 1 | Оқылым | «Қай қалада?» — 6 памятников: Астана / Алматы / Түркістан | каждое верное — 0,5 балла | 3 |
| 2 | Жазылым | Падежи: мүсін + нің, ге, ді, де, нен, мен | каждое верное — 0,5 балла | 3 |
| 3 | Жазылым | Послелоги туралы, үшін, кейін, бірге (5-т., стр. 120) | каждое верное — 0,5 балла | 2 |
| 4 | Айтылым | Рассказ о Бәйтереке или Ханшатыре: высота / материал / на что похож | 3 факта — 3; грамматика — 1 | 4 |
| 5 | Тыңдалым | Загадка «Сәулеті сұлу-ақ…» и 2 вопроса о Кок-Тобе | отгадка — 1; ответы — 2 | 3 |
| | | | **Итого** | **15** |

**Перевод баллов части Б в проценты:** балл ÷ 15 × 100. Пример: 12 из 15 = 80 % → вместе с частью А 90 % → (80+90)/2 = 85 % → «5».

## 5. Работа с результатами
- **«2» / «3» по одному навыку** — назначить повтор урока, где этот навык был слабее: в «Мұғалім парағы» видно, какой навык просел.
- **Игра < 65 %** — пройти игру ещё раз в тот же день и через 2 дня (интервальное повторение).
- **Все навыки ≥ 85 %** — задания ★★★: проект «Зерттеу жасаймын», роль консультанта в паре.
