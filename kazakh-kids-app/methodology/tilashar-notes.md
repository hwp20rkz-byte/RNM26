# Разговорники «Тілашар» (Тіл комитеті, 2011) → что взять в QazaqVerse

Прочитаны четыре книги серии «Орысша-қазақша тілашар / Русско-казахский разговорник» (составители
А.Ж. Төрениязова, Ж.А. Тұрлыбекова, Ү.К. Каюпова; Астана, 2011): **Шаңырақ / Дом**, **Спорт**,
**Денсаулық / Здоровье**, **Білім / Образование**. Две книги — текстовые PDF, две — сканы (прочитаны постранично).

## Главное

1. **Это пособия для взрослых специалистов**, а не учебники для 1–4 классов. Большая часть фраз детям не подходит
   («Сколько у вас было родов?», «Какой проходной балл?», устройство системы образования). Переносить их построчно нельзя.
2. **Ценность — в конструкциях и темах**, а не в готовых фразах. Ниже — то, что ребёнок реально говорит и слышит.
3. **Авторское право**: книги изданы Комитетом по языкам; в игру мы пишем **свои примеры** на тех же конструкциях,
   цитаты не копируем.
4. **В текстовых PDF есть ошибки распознавания** (например, «2/3 — екіден үш» вместо правильного «үштен екі»,
   «екі бүгін» вместо «екі бүтін»). Любую фразу из этих файлов перед использованием проверяем по грамматическому движку
   и словарю.

## Что берём — по книгам

### Денсаулық / Здоровье — самое полезное
| Конструкция | Пример (наш) | Зачем ребёнку | Куда в игре |
|---|---|---|---|
| **Вежливый приказ -ыңыз / -іңіз** (команды врача) | Отырыңыз! Аузыңызды ашыңыз! Терең дем алыңыз! Жоғары қараңыз! | понять врача, медсестру, учителя | ✅ **сделано**: режим «Бұйрық» в «Сөйлем экспресі»; карточка «Бұйрық рай» — спринт 2 |
| **Менің … ауырады** (притяжательность 1 л. + ауырады) | Басым ауырады. Тісім ауырады. Ішім ауырады. | сказать взрослому, что болит — это безопасность | новая тема разговорника «Дәрігерде» + тренажёр «Что болит?» (спринт 2) |
| Вопросы врача | Қай жерің ауырады? Қызуың бар ма? | понять вопрос | диалог по ролям «Дәрігерде» (спринт 2) |
| Скорая помощь | Жедел жәрдем! Мекенжайым: … | назвать адрес, номер 103 / 112 | короткая карточка «Если нужна помощь» (спринт 6) |

### Білім / Образование
| Конструкция | Пример (наш) | Куда |
|---|---|---|
| Школьная лексика | оқу жылы, оқулық, сабақ, пән, үзіліс, демалыс (каникулы), баға | словарь «Мектеп» (+ слова, которых ещё нет) |
| Вопросы о школе | Сен қай сыныпта оқисың? Сыныпта қанша оқушы бар? Бүгін неше сабақ болады? | разговорник, тема «Класс» (спринт 2) |
| Оценки | бес, төрт, «өте жақсы», «жақсы» | тема «Класс» |
| **Обращения** (раздел «Тіл қатысу») | Ата, отырыңыз! Балам, … Қарындас, … Інішек, … | карточка «Как обратиться к старшему и младшему» — культура уважения (спринт 2) |

### Спорт
| Конструкция | Пример (наш) | Куда |
|---|---|---|
| **Маған … ұнайды** (дательный падеж + ұнайды — «мне нравится») | Маған футбол ұнайды. Саған не ұнайды? | карточка грамматики + тренажёр (спринт 2): русскоязычные дети говорят «Мен ұнайды» — типичная ошибка |
| … ойнаймын / …-мен айналысамын | Мен футбол ойнаймын. Мен жүзумен айналысамын. | тема «Спорт» в разговорнике (спринт 6) |
| **Ұлттық ойындар** | асық ату, тоғызқұмалақ, бәйге, қазақ күресі, көкпар | тема «Ұлттық ойындар» — связка с нашей игрой «Асық үйіру» (спринт 6). «Қыз қуу» детям не даём. |
| Команды на физкультуре | Тұр! Отыр! Секір! Қолыңды көтер! | игра «Мұғалім айтады» (вариант «Симон говорит»), спринт 2 |

### Шаңырақ / Дом
О себе, семья, дом, приветствия уже есть в игре (уроки 1–3 классов и разговорник). Новое:
| Конструкция | Пример (наш) | Куда |
|---|---|---|
| **жарты, ширек** (половина, четверть) | Сағат бес жарым. Ширек қалды. | урок «Уақыт» (3 класс): часы — спринт 4 |
| Приблизительные числа | он шақты, жүздеген, отызға тарта | позже, 4 класс |

## Не берём
Деловая и медицинская лексика для взрослых, роды, брак, поступление в вуз, экзаменационные сессии, рецепты и дозировки
лекарств, устройство системы образования и законов, игры с поцелуями («қыз қуу»).

## Итог: новые темы для детей (в порядке пользы)
1. **Команды учителя и врача** (бұйрық рай) — ✅ начато в «Сөйлем экспресі».
2. **Что болит?** — Менің басым ауырады: здоровье и безопасность.
3. **Маған … ұнайды** — как сказать «мне нравится» без кальки с русского.
4. **Обращения** — Ата / Әже / апай / аға / балам / қарындас / інішек.
5. **Школа**: вопросы о классе, уроках, оценках, каникулах.
6. **Спорт и ұлттық ойындар**.
7. **Часы: жарты, ширек**.
