# План разработки QazaqVerse — спринты и ежедневный журнал

Обновляется **каждый день** (запланированная задача «QazaqVerse: ежедневный спринт и напоминания», 10:23 по Астане):
что сделано, что дальше, что ждёт решения владельца. Один спринт = одна законченная
вещь, которую можно поставить ребёнку: контент + озвучка + тесты + сквозная проверка на телефоне + тестовый APK.

## Правила (Definition of Done)
1. Казахский текст — свои примеры; каждая форма проверена грамматическим движком или тестом.
2. Озвучка: ISSAI + ISEKE для всех новых фраз; «Томирис» — когда есть ключ Freedom Speech (иначе звучит ISSAI).
3. Тесты: модульные (`npm test`, `cd suite && npx vitest run`) и сквозные на телефоне 400×860 и десктопе.
4. Скриншоты смотрю глазами: тесты не ловят наложение подписей и обрезанные края.
5. Тестовый APK собран; коммит и push в ветку разработки.
6. Методические материалы обновлены: `methodology/games-in-class.md` (как использовать на уроке) и этот журнал.
