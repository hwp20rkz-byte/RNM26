# Қазақша Ойна — казахский для детей

Офлайн-игра для Android в формате «урок по 10 заданий» (сердечки, очки, серия дней, звёзды, тропинка уроков).
Контент — по учебнику, раздел **«3. Уақыт»**, тема **«Менің күн тәртібім»**.

**Готовый APK:** [`dist/qazaqsha-oyna.apk`](dist/qazaqsha-oyna.apk) (~180 КБ, Android 5.0+, без интернета и без разрешений).

## Что внутри

| Бөлім | Уроки |
|---|---|
| 1. Сандар (Числа) | 1–10 · десятки · жүз, мың, теңге («Бес жүз теңге») |
| 2. Уақыт (Время) | Сағат неше? · жарым (7:30) · нешеде? (жетіде, сегізде, -да/-де/-та/-те) |
| 3. Күн тәртібі | таңертең/түсте/кешке · таңғы/түскі/кешкі ас · тұрамын, барамын… · расписание дня |
| 4. Сөйлесейік | менің/сенің/сіздің/оның күн тәртібі · вопросы «Ол нешеде тұрады?» · Анна: ішті / ішіп жатыр / ішеді · большое повторение |

12 типов заданий: карточки новых слов, выбор картинки, перевод на казахский, «найди пары», сборка предложения из плиток,
выбор перевода, пропуск в предложении (включая окончания падежей и притяжательные), циферблат → время,
время → циферблат, «нешеде?» по часам, число → слова, распорядок дня по порядку, аудирование.
Ошибочные задания возвращаются в конец урока. Есть раздел «Сөздік» (словарь) и режимы тренировки.

**Озвучка.** Казахские слова читает системный синтез речи Android. Если на телефоне нет казахского голоса,
игра работает полностью, но без озвучки слов (в профиле есть кнопка «Настроить озвучку»).

## Установка

1. Скопировать `dist/qazaqsha-oyna.apk` на телефон и открыть.
2. Разрешить «Установку из неизвестных источников» для файлового менеджера/браузера.
3. Play Protect может предупредить о неизвестном разработчике — это нормально для APK не из Google Play.

## Сборка

Без Gradle, инструментами из Ubuntu:

```bash
sudo apt-get install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
node tools/make-icons.js   # иконки из android/icon.svg (нужен Playwright)
./build.sh                 # → dist/qazaqsha-oyna.apk
```

Веб-часть (`web/`) открывается и в обычном браузере — удобно для правки заданий.
Учебный контент целиком лежит в `web/data.js`.

`android/release.keystore` — ключ подписи для домашней установки (пароль в `build.sh`).
Он нужен, чтобы новые версии ставились поверх старой без потери прогресса.
Для публикации в Google Play сгенерируйте собственный ключ и не храните его в репозитории.
