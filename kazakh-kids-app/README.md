# Қазақша Ойна — казахский для детей 1–3 класса

Офлайн-игра для Android: тропинка уроков по 10 заданий, сердечки, очки, монеты, серия дней, звёзды,
герои, мини-игры, магазин подарков и альбом наклеек. Все казахские слова и фразы озвучены прямо в приложении,
поэтому звук работает на любом телефоне, в том числе на Huawei без казахского голоса в системе.

**Готовый APK:** [`dist/qazaqsha-oyna.apk`](dist/qazaqsha-oyna.apk) (~5 МБ, Android 5.0+, без интернета и без разрешений).
Версия 2.0 ставится поверх 1.0, прогресс сохраняется.

## Уроки (46)

| Класс | Разделы |
|---|---|
| 1-сынып | Сәлем! (приветствие, знакомство) · Әліппе (ә ө ү ұ і, қ ғ ң һ) · Отбасы · Түстер · Сандар · Жануарлар · Мектеп · повторение |
| 2-сынып | Жыл мезгілдері и ауа райы · Апта күндері и айлар · Дастархан (фрукты, овощи, национальная еда) · Дене мүшелері · Киім · Менің үйім (үстінде/астында/ішінде) · повторение |
| 3-сынып | Уақыт · Күн тәртібі (по учебнику, раздел «3. Уақыт») · Сөйлесейік · Мамандықтар · Қала мен көлік · Менің Отаным (символы, Наурыз) · повторение |

Грамматика внутри заданий: окончания -да/-де/-та/-те, -ға/-ге/-қа/-ке, -мен/-бен/-пен, притяжательные (анам, әкем, дәптерім),
лица глагола (оқушымын/сың), времена (ішті / ішіп жатыр / ішеді), послелоги места.

## Игра

- **Герои:** Барыс, Құлыншақ, Қоянжан, Түлкішек, Аюжан, Ботақан, Қыранжан. Каждый ведёт свой раздел; любого можно купить и сделать своим другом.
- **Мини-игры:** Кім жылдам? (викторина на время), Жұбын тап (пары карточек), Карточкалар (учим слова), а за монеты открываются Шарлар (лопни шарик), Әріп аулау (казахские буквы) и Дұрыс па? (верно/неверно на время). Ещё 5 тренировок: смешанная, часы, числа, сборка предложений, аудирование.
- **Награды:** монеты за уроки и игры, подарок дня, сундук за новый уровень (каждые 100 XP), 16 достижений с бонусами, 24 наклейки трёх редкостей.
- **Магазин:** герои, игры, коробка с наклейкой, +2 сердечка, защита серии дней.

## Озвучка

Голос — модель **KazakhTTS** (ISSAI, Назарбаев Университет), лицензия CC BY 4.0, синтез [Piper](https://github.com/rhasspy/piper).
1024 фразы заранее записаны в `web/audio/*.mp3`. Пересоздать после правки контента:

```bash
curl -L -O https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-kk_KZ-issai-high.tar.bz2
tar xjf vits-piper-kk_KZ-issai-high.tar.bz2
pip install piper-tts                                  # и ffmpeg
node tools/collect-phrases.js > /tmp/phrases.json
python3 tools/make-audio.py /tmp/phrases.json vits-piper-kk_KZ-issai-high/kk_KZ-issai-high.onnx
```

## Установка

1. Скопировать `dist/qazaqsha-oyna.apk` на телефон и открыть.
2. Разрешить установку из неизвестных источников для файлового менеджера/браузера.
3. Play Protect / AppGallery может предупредить о неизвестном разработчике — это нормально для APK не из магазина.

## Сборка

Без Gradle, инструментами из Ubuntu:

```bash
sudo apt-get install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
node tools/make-icons.js   # иконки из android/icon.svg (нужен Playwright)
./build.sh                 # → dist/qazaqsha-oyna.apk
```

Веб-часть (`web/`) открывается в обычном браузере. Контент: `web/grade1.js`, `grade2.js`, `grade3.js`;
герои, наклейки, достижения и цены: `web/world.js`; мини-игры: `web/games.js`.

`android/release.keystore` — ключ подписи для домашней установки (пароль в `build.sh`), чтобы обновления
ставились поверх старой версии. Для Google Play сгенерируйте собственный ключ и не храните его в репозитории.
