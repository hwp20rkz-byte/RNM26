# QazaqVerse: Tíl Quest — казахский язык как игра

Офлайн-игра для Android: школьная программа 1–3 классов и живая разговорная речь, блочные 3D-герои,
четыре аркады, живой аукцион, ежедневный бросок асыков и оценка произношения.
Два режима обучения: **Русский → Қазақша** и **English → Қазақша**.

**Готовый APK:** [`dist/qazaqsha-oyna.apk`](dist/qazaqsha-oyna.apk) (Android 5.0+).
Версия 3.3 ставится поверх 1.0–3.2: уроки, очки, монеты (теперь «Алтын Асық»), герои и наклейки сохраняются.

**Новое в 3.3 — модули 2 «Жақсыдан үйрен, жаманнан жирен» и 4 «Сәулет өнері»** (стр. 38–53 и 108–138):
16 уроков по учебнику, три новых типа заданий — «Жалғау шебері» (окончания по сингармонизму),
«Қатені тап» (как слышится и как пишется: [ұқұпту] — ұқыпты) и перетаскивание шылау (үшін, туралы, себебі…);
босс-чекпоинты (5 минут, 3 ❤️) с советом по самой слабой категории ошибок; ролевые диалоги с ветвлением
(«Автобустағы жағдаят», интервью у Бәйтерека) с ответом голосом; 3D-игры «Тіл Кереметі» (колесо с загадками
учебника), «Сәулетші шеберханасы» (собери Бәйтерек, Ханшатыр, макет сарая) и «Жақсы істер бөлмесі»
(уборка комнаты Жалқаубека); голоса персонажей Әлібек, Жалқаубек, Ата, Әже, шетелдік сәулетші.
Код модулей — TypeScript в [`src/`](src/) (`npm install && npm run build`, тесты `npm test`), данные —
[`src/data/curriculum.json`](src/data/curriculum.json) с валидацией; сверка промта с учебником —
[`methodology/textbook-notes-m2-m4.md`](methodology/textbook-notes-m2-m4.md).

**Новое в 3.1 — трек «Оқулық» по учебнику «Қазақ тілі», 3 класс** (модули 1 «Жанды табиғат» и 3 «Уақыт»):
22 урока с номерами страниц, правилами «Тілдік бағдар», стихами «Кел, жаттайық» и «Есте сақта»;
22 тематические игры для закрепления (классификация, пары, порядок, часы) — открываются после урока;
итоговые уроки модулей с отметкой 2–5 и разбивкой по навыкам; «Мұғалім парағы» для учителя в профиле;
голос ISEKE по умолчанию (переключается на ISSAI в профиле).
Методическое пособие: [`methodology/metodika-3-klass.docx`](methodology/metodika-3-klass.docx)
(поурочные разработки, дескрипторы, СОР); собирается из данных игры: `node tools/make-methodology.js`.

**Тестовый APK для проверки:** [`dist/qazaqsha-oyna-test.apk`](dist/qazaqsha-oyna-test.apk) — «Test QazaqVerse»,
отдельный пакет `kz.qazaqsha.oyna.test` (ставится рядом с обычной игрой, прогресс раздельный). Открыты все уроки
всех треков, все тематические игры, мини-игры и герои; 99 сердец; в уроке кнопка «⏭ TEST» засчитывает задание;
вверху метка TEST. Сборка: `TEST=1 ./build.sh`. В обычном APK файла `test-mode.js` нет — блокировки работают.

## Что внутри

**Обучение — 93 урока, 16 типов заданий**

| Трек | Разделы |
|---|---|
| 1-сынып | Сәлем! · Әліппе (ә ө ү ұ і, қ ғ ң һ) · Отбасы · Түстер · Сандар · Жануарлар · Мектеп |
| 2-сынып | Жыл мезгілдері · Апта мен ай · Дастархан · Дене мүшелері · Киім · Менің үйім |
| 3-сынып | Уақыт · Күн тәртібі · Сөйлесейік · Мамандықтар · Қала мен көлік · Менің Отаным |
| Оқулық (3 кл.) | Жанды табиғат (12) · Жақсыдан үйрен, жаманнан жирен (6) · Уақыт (10) · Сәулет өнері (10) — строго по учебнику, с оцениванием |
| Тірі тіл | Қалайсыз? · Базарда · Жолда · Қонақта · Кафеде — фразы из жизни с грамматическими подсказками |

В режиме RU→KK подсказки объясняют падежи и сингармонизм, в режиме EN→KK — агглютинацию и порядок слов SOV
(например: после числа множественное число не ставится — *екі бауырсақ*, не *екі бауырсақтар*).

**Сөздік — справочник и тренажёры (вкладка 📖):**

| Раздел | Что внутри |
|---|---|
| 💬 Тілашар | 16 тем разговорника (приветствие, класс, семья, дастархан, магазин, город, транспорт, время, погода, здоровье, праздники, чувства, хобби, телефон…), 179 фраз, 9 диалогов с проигрыванием по ролям, тест по каждой теме |
| 🧩 Грамматика | 13 карточек с живыми таблицами: 9 букв, сингармонизм, множественное число, 7 падежей, тәуелдік, жіктік, 5 форм глагола, ма/ме, местоимения, числа, послелоги, порядок слов, степени сравнения; 5 тренажёров |
| 📖 Сөздік | поиск по всем словам, фразам, пословицам (RU/EN/KK), 14 тематических словарей (266 слов) + слова уроков |
| 📜 Мақалдар | 48 пословиц по 8 темам, игра «Продолжи пословицу», 6 авторских скороговорок на звуки ә ғ қ ү ұ ө |
| 🎭 Тіркестер | 32 фразеологизма: дословный перевод и настоящий смысл, игра «Угадай смысл» |

Все формы в таблицах строит `web/grammar-core.js`, и каждую сверяет с ответом, записанным вручную,
`tests/grammar.test.js` (1206 проверок). Так ошибка правила не дойдёт до ребёнка.

**Герои (Blocky Neo-Chibi, настоящий 3D на three.js):** Батыр-X, Айсұлу Neon, Тайсон-Тайпақ, Әже-Bot 3000 —
у каждого свой голос и фирменное движение (Shattyq Slam, Electro-Shuffle, 360 Kickflip, Бата).
Семь зверей из прошлых версий остались проводниками по разделам.

**Аркады (60–90 секунд):**

- **Көк Базар Rush** — спроси цену, расслышь её на слух, поторгуйся, ударь по рукам, оплати переводом.
- **Аул Cyber-Drift** — 3D-раннер: навигатор командует по-казахски, отвечаешь свайпом. Дальше — только на слух.
- **Дастархан Master** — рассади гостей (старших — на төр) и скажи каждому нужные слова уважения.
- **Айтыс Beat Battle** — ритм-дуэль: слова рифмованной строчки нужно ловить в бит.

**Экономика:** Алтын Асық вместо монет, Шежіре XP и пять лиг с недельной таблицей, задания дня,
комбо-серии в уроках, **3D-аукцион** каждые 6 часов (боты, молоток с вибрацией, «Бір! Екі! Сатылды!»,
защита от ставки в последнюю секунду) и **«Асық үйіру»** — ежедневный бросок четырёх асыков
(четыре «алшы» = джекпот и ×2 XP на сутки). На аукционе разыгрываются скины, питомцы и следы.

**Голос.** Все 3636 казахских слов и фраз озвучены внутри APK, работают без интернета на любом телефоне.
Оценка произношения (задание «Айт!») включается, если есть распознавание речи — см. ниже.

## Голоса Freedom Speech (Томирис, Таймас, клоны)

`tools/make-audio-fs.mjs` озвучивает фразы игры через API [Freedom Speech](https://freedomspeech.kz/docs) (npm `freedomspeech`)
**на компьютере разработчика**: ключ остаётся у вас, в APK попадают обычные mp3, игра работает офлайн.
Готовый пакет сам появляется в «Мен → Дауыс» рядом с ISEKE и ISSAI; фраз, которых в пакете нет, озвучит ISSAI.

```bash
node tools/collect-phrases.js > /tmp/phrases.json
export FS_API_KEY=...                                             # кабинет console.freedomspeech.kz; в репозиторий не класть
npm run audio:fs -- /tmp/phrases.json --voice tomiris --limit 20  # сначала послушать 20 файлов в web/audio-tomiris/
npm run audio:fs -- /tmp/phrases.json --voice tomiris --verify    # весь пакет + обратное распознавание → verify.csv
npm run audio:fs -- /tmp/phrases.json --voice taymas              # мужской голос
npm run audio:fs -- /tmp/phrases.json --voice tomiris --pack tomiris-cast --label "Томирис + герои" --cast
npm run audio:fs -- --list-voices                                 # каталог голосов (когда его опубликуют на api-адресе)
npm run audio:fs -- /tmp/phrases.json --clone apai.wav --pack apai --label "Баян апай" --base-url <адрес с /api/voice-clone>
```

| Режим | Что делает |
|---|---|
| по умолчанию | только реплики диктора (как пакет ISEKE); герои сохраняют свои голоса ISSAI |
| `--cast` | ещё и реплики героев: девочки и бабушки → tomiris с эмоцией (Әнел, Айсұлу — `happy`), мальчики и деды → taymas; старшие говорят `<slower>` |
| `--transport http` | `POST /v1/audio/speech` вместо WebSocket (по умолчанию поток `/ws/tts`, модель `freedomspeech`; `--model freedomspeech-flash` быстрее) |
| `--verify` | каждый новый файл распознаётся обратно, похожесть < 0,80 — в `verify.csv` на прослушивание |
| `--clone` | клон голоса по записи **только с согласия его владельца** (например, учитель записывает 15 секунд) |

Запуск можно прервать: повторный пропускает готовые файлы. 429 и сбои сервиса повторяются с паузой; 401/402 останавливают
сразу. `--prune` удаляет файлы фраз, которых больше нет. Тест без сети и ключа: `npm run test:voice-packs` (локальный мок API).
Перед релизом проверьте в оферте Freedom Speech право распространять сгенерированное аудио в приложении — лицензия MIT
относится только к коду SDK.

## Оценка произношения

Телефон сам большую модель распознавания не потянет, поэтому уровней три:

1. **Сервер QazaqVerse Voice** — по HTTPS через интернет (или свой [`backend/`](backend/README.md) в домашней сети).
   Профиль → «Дауыс · оценка произношения» → вставить адрес **вместе с ключом** одной строкой:
   `https://<хост>:8443/k/<КЛЮЧ>` → «Проверить сервер». Ключ выдаёт владелец сервиса; в коде и в репозитории его нет,
   в профиле он показывается замаскированным (`/k/abc•••`).
2. **Распознавание самого телефона** (kk-KZ) — если оно есть (обычно телефоны с сервисами Google).
3. **Без микрофона** — всё работает бабблами и свайпами, задания «Айт!» просто не показываются.

Как клиент работает с API (`web/voice.js`):

| Что | Как |
|---|---|
| `GET /health` | при запуске, при возврате в приложение и не чаще раза в минуту, если сервер был недоступен; таймаут 5 с; задания «Айт!» появляются только при `ok: true` |
| `POST /assess` | WAV 16 кГц, моно, PCM 16 бит, до 9 с; `target` ≤ 300 символов; таймаут 30 с с настоящим `abort`. Балл, `passed`, `missed` и подсказка берутся **с сервера**, локально считается только раскраска букв |
| `GET /tts` | только для фраз, которых нет во встроенной озвучке (уроки остаются офлайн и не тратят лимит 30 запросов в минуту) |
| `silence` | «Не слышу тебя» — повторить |
| 401 / 429 / 503 / сеть | понятное сообщение; кнопка «Пропустить» становится полноценной; после 429 — минута без запросов, без повторов в цикле |

Контрактный тест клиента против мок-сервера с тем же API: [`tests/voice-api/`](tests/voice-api/) (19 проверок, фальшивый микрофон Chromium).

Неудачная попытка сказать вслух никогда не отнимает сердечко. Формула, замеры трёх моделей и ограничения —
в [`backend/README.md`](backend/README.md).

## Разрешения

Игра по-прежнему полностью офлайн. Три разрешения нужны только для необязательных функций:
`VIBRATE` (молоток аукциона), `RECORD_AUDIO` (задание «Айт!», спрашивается при первом нажатии на микрофон),
`INTERNET` (только для сервера голоса, если его адрес вписан в профиле). Без адреса ничего никуда не отправляется;
с адресом на сервер уходит запись фразы для оценки — по описанию сервиса она не хранится. Голос ребёнка — персональные
данные: при публикации в магазине это нужно указать в политике конфиденциальности.

```
  phrasebook-data.js     разговорник, диалоги, пословицы, фразеологизмы, тематический словарь

tests/          npm test (ядро, движок уроков, грамматика) · node tests/phrasebook.e2e.js

```

## Сборка

```bash
sudo apt-get install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
./build.sh                 # → dist/qazaqsha-oyna.apk
```

Озвучка (после правки контента):

```bash
node tools/collect-phrases.js > /tmp/phrases.json
python3 tools/make-audio.py /tmp/phrases.json vits-piper-kk_KZ-issai-high/kk_KZ-issai-high.onnx
```
