# QazaqOSI — Интерактивный тарифный калькулятор сметы ОСИ / ПТ

Веб-приложение для расчёта прозрачного, юридически обоснованного тарифа на
управление объектом кондоминиума и содержание общего имущества
многоквартирного жилого дома (МЖД) в Казахстане.

## Методологическая база

- **Закон РК «О жилищных отношениях»** — разделение расходов на управление и
  содержание, обязательный накопительный взнос на капремонт (не менее 0,005
  МРП/м²/мес.).
- **Приказ Министра индустрии и инфраструктурного развития РК от 30.03.2020
  №166** «Методика расчета сметы расходов на управление объектом
  кондоминиума и содержание общего имущества» — структура статей и формула
  тарифа: `В = (Р год − Д год) / (S полез. × 12)`.
- **Налоговый и Социальный кодексы РК** — расчёт ОПВ, ВОСМС, ИПН, СО, СН,
  ОСМС, ОПВР с ФОТ (см. `src/lib/calculator/payrollTax.ts`).

### Калибровка данных

Структура категорий и значительная часть цен (142 позиции расходных
материалов на инженерное обслуживание, штатное расписание председателя,
статьи содержания офиса, текущего ремонта и хоз. расходов) калиброваны на
**реальной действующей смете ОСИ ЖК «Коркем-1»** (Алматы, 2026-2027 гг.),
предоставленной пользователем. Эти позиции помечены в коде источником
`REAL_SOURCE`.

Позиции, отсутствующие в исходной смете (СИЗ по нормам, лифтовое хозяйство,
альпинистские работы, охрана/консьерж для бизнес-класса, справочник
минимальных тарифов маслихатов и др.), проставлены рыночными **оценками**
2025-2026 гг. и помечены `MARKET_ESTIMATE` — они явно обозначены в
интерфейсе (тултип «Источник») и **требуют сверки перед утверждением сметы**
на общем собрании собственников.

⚠️ Справочник минимальных тарифов маслихатов (`src/lib/calculator/minTariffs.ts`)
и стандартный вычет по ИПН (кратность МРП) — иллюстративные величины,
единого официального реестра нет; сверяйте с решением маслихата вашего
региона и действующей редакцией Налогового кодекса РК на расчётный год.

## Стек

- **Next.js 16 (App Router) + TypeScript + Tailwind CSS v4**
- **Zustand + persist (localStorage)** — мультипроектный стор: несколько
  объектов расчёта, каждый со своей базой статей, пересчёт тарифа на каждое
  изменение в реальном времени
- **Recharts** — donut-диаграмма распределения бюджета, bar-чарт затрат на м²
- **exceljs** — экспорт в Excel с реальными формулами (`SUM`, арифметика),
  4 вкладки: Сводный тариф / Детализация затрат / Спецификация ФОТ и СИЗ /
  План регламентных работ; тот же exceljs разбирает загружаемые .xlsx
  прайс-листы в Справочнике
- **docx** — официальный документ сметы для общего собрания
- **@media print** — печать/PDF без сторонних библиотек
- **Zod** — валидация профиля объекта
- **Vitest** — unit-тесты расчётного движка, налогового модуля, store и
  парсера прайс-листов

## Мультипроектность, справочник и сохранение смет

- **Несколько объектов** — не только жилой кондоминиум: любой жилой,
  смешанный или чисто нежилой объект (офис, ТЦ, паркинг). Переключатель
  объектов наверху страницы: создать новый (с чистой структурой статей или
  клоном эталона «Коркем-1»), переименовать, удалить.
- **Инлайн-редактирование** — в Шаге 2 количество, единица измерения, цена,
  название, численность и оклад редактируются прямо в строке; переключатель
  штат/аутсорс; добавление и удаление любых позиций и сотрудников.
- **Справочник статей расходов** (вкладка рядом с Конструктором) —
  общая база материалов/услуг, не привязанная к объекту: поиск, CRUD,
  **загрузка прайс-листов** (.csv/.xlsx с гибким распознаванием заголовков
  колонок) и добавление записей каталога в любой проект одним кликом.
- **Сохранение смет** — «Сохранить смету» замораживает снимок текущего
  расчёта (профиль, статьи, тариф) под объектом; список версий с
  восстановлением и удалением.
- **Конструктор пресетов обслуживания** (вкладка «Пресеты») — «Класс
  обслуживания» в Шаге 1 и сравнение в Шаге 3 — это одна и та же сущность
  (`ServicePreset`), а не два независимых списка, как было раньше. Пресет
  одним выбором: масштабирует цены всех статей (`priceMultiplier`),
  отключает статьи выше потолка класса (`maxServiceClass`, по полю
  `minServiceClass` статьи/оклада) и проставляет в профиль объекта взнос на
  капремонт и коэффициент для нежилых. 4 встроенных пресета
  (Эконом/Комфорт/Бизнес/Премиум) редактируются как есть или дублируются в
  свои — характеристики каждого поля расшифрованы прямо в интерфейсе.
- ⚠️ Всё это хранится **локально в браузере** (`localStorage`) — сайт
  статический, без бэкенда/базы данных. Данные не синхронизируются между
  устройствами и стираются при очистке данных сайта или в приватном окне.

## Структура

```
src/
  lib/calculator/
    types.ts            — доменная модель (+ Project, SavedSmeta, CatalogEntry)
    payrollTax.ts        — налоги на ФОТ (РК)
    database.ts           — дерево категорий 1.x/2.x, эталонная и «пустая» базы
    data/engineeringConsumables.ts — 142 реальные позиции расходников
    catalogSeed.ts          — преобразование базы в записи справочника
    engine.ts             — расчёт тарифа, категорий, сценариев
    presets.ts             — сценарии, класс жилья, шаблон нового объекта
    minTariffs.ts           — справочник минимальных тарифов (иллюстративно)
    validation.ts            — Zod-схема профиля объекта
  lib/import/parsePriceList.ts — разбор .csv/.xlsx прайс-листов
  lib/export/
    exportToExcel.ts       — генерация .xlsx с формулами
    exportToDocx.ts         — генерация официальной сметы .docx
  store/
    useProjectsStore.ts    — мультипроектный Zustand-стор (persist)
    hooks.ts                 — useActiveProject / useActiveTariff
  components/               — конфигуратор объекта, конструктор статей,
                               справочник, переключатель объектов, sticky HUD,
                               сравнение сценариев, графики, экспорт
```

## Известные упрощения (честно, без замалчивания)

- Не все атомарные позиции из ТЗ (десятки видов СИЗ на роль, полный каталог
  дворового инвентаря) перечислены поштучно — покрыта репрезентативная
  глубина по каждой категории с расширяемой структурой данных.
- Количество некоторых позиций эталонной базы (лампочки, доводчики и т.п.)
  зафиксировано под конкретный дом (ЖК «Коркем-1») и не масштабируется
  автоматически под параметры другого объекта — при выборе шаблона «Копия
  эталона» количества нужно скорректировать вручную в Шаге 2, либо начинать
  новый объект с пустого шаблона и наполнять его из Справочника.
- Формула социального налога (СН) в модуле `payrollTax.ts` — общая
  аппроксимация по Налоговому кодексу РК; для ОСИ как НКО возможен иной
  режим налогообложения — сверьте с бухгалтером.
- PDF-экспорт реализован через нативную печать браузера (`window.print()` +
  `@media print`), а не через headless-рендеринг сервера — визуально
  соответствует print-стилям приложения.
