Made-in-China по одобренному запросу присылает до 20 котировок от проверенных поставщиков. У Alibaba.com открытого API поиска нет, Open Platform доступна только одобренным партнёрам. Поэтому уровень 3 нужен с первого дня, а не «на потом».

Условия API меняются: проверять на старте проекта

Search-агент сначала идёт в уровень 1, затем 2. Если ничего не нашёл, ставит оператору задачу уровня 3 с готовыми ключевыми словами на китайском. Уровень 4 запускается параллельно для сложных и нестандартных товаров.
