# SinoSource OS

Концепт системы для байер-агента, который ищет товары и заводы в Китае для клиентов из РФ и РК.

- `CONCEPT.md` — полная концепция: процесс, агенты, архитектура, доступ к площадкам, мессенджеры, цены в ₽ ₸ ¥ $, аналоги, план, риски.
- `prototype.html` — анимированный прототип кабинета с озвучкой (Web Speech API). Это фрагмент страницы без `<html>`/`<head>`; опубликован как артефакт: https://claude.ai/artifact/SLhW99cabtrFkPmTzjmFEd
- `deck/` — исходники презентации (формат Slides-артефакта): https://claude.ai/artifact/UYt88CCmcw57iTryE2ASEn
