# QDesign: инструмент «Детали», настройка отдельной панели модуля

## 1. Источник

- **Файл:** `scratchpad/vids/v1.mp4` (922×720, h264, 3:52). Скринкаст qdesign.kz со вшитыми заголовками шагов (сверху) и субтитрами (снизу). Звук не анализировался, речь автора взята только из субтитров.
- **Отрезок:** 0:00–3:52, весь ролик.
- **Тема:** раздел «Детали» панели «Настройка модуля». Здесь выбирают отдельную панель корпуса и меняют только её: материал, направление текстуры, кромку по сторонам L1/L2/W1/W2, удлинение стороны. Деталь можно удалить и восстановить. Несколько деталей выбирают через Ctrl, деталь можно выбрать и из списка.
- **Как извлекались кадры:** `watch.py --no-dedup --fps 0.34 --resolution 922`, 79 кадров с шагом около 3 с. Спорные числа проверены отдельными увеличенными кадрами ffmpeg (crop + scale ×3) на 0:01, 0:18, 0:34, 0:50, 0:57, 1:03, 1:06, 1:29, 1:53, 2:26, 2:28, 2:47–2:51, 2:55, 3:06, 3:20, 3:28, 3:33, 3:45.
- **Объект:** нижний напольный модуль «01. Модуль 1»: 600 × 720 × 560 мм, цоколь 95, корпус «ЛДСП — Дуб сонома», задняя стенка «ХДФ — ХДФ», одна распашная дверца с ручкой-скобой.

### 4.2 Левая плавающая панель «Модули»

- Заголовок «Модули» и кнопка свернуть ««».
- Строки «01. Модуль 1» и «02. Модуль 2». Активная строка залита оранжевым. В каждой строке иконка глаза (видимость) и «+».
- Модуль 2 на сцене не попадает в кадр, кроме края: судя по субтитру «выбираем нижний модуль», модуль 1 нижний.

## 5. Модель данных, которую можно вывести

```ts
type PartOrientation = 'vertical' | 'horizontal' | 'frontal'; // «Вертикальный» | «Горизонтальный» | «Фронтальный»
type EdgeSide = 'L1' | 'L2' | 'W1' | 'W2';                     // L — длинные стороны, W — короткие

interface PartOverride {          // хранится в модуле по ключу роли детали, а не в самой детали
  partRole: string;               // 'sideLeft' | 'sideRight' | 'bottom' | 'topRailFront' | 'topRailBack' | 'plinth' | 'facade1' | 'back'
  name?: string;                  // «Бүйір L» и т.п.; по умолчанию имя роли
  materialId?: string;            // отдельный материал детали поверх материала корпуса
  grain?: 'length' | 'width';     // «Текстура: по длине / по ширине»
  edges?: Partial<Record<EdgeSide, {
    enabled: boolean;             // оранжевая вкладка
    extendMm: number;             // удлинение (+) / укорочение (−) стороны, мм
    plusP?: boolean;              // «+П» — смысл не показан
    plusG?: boolean;              // «+Г» — смысл не показан
  }>>;
  cornerRadiusMm?: [number, number, number, number]; // «Скругление углов, R мм», порядок углов не подписан
  deleted?: boolean;              // удалённая деталь видна в секции «Удалённые детали», восстанавливается
}
```

- Перекрытия живут на уровне детали внутри модуля, не на уровне модуля [Видно t=01:02]: материал сменился у трёх деталей, дверца не изменилась.

## 7. UX-находки

1. **Режим выбора детали отдельной кнопкой (горячая клавиша A).** Клик по сцене выбирает панель, а не модуль. Разделение режимов «модуль / деталь» снимает двусмысленность клика [Видно t=00:15].
2. **Мультивыбор через Ctrl+клик**, одна правка применяется ко всем выбранным: материал трём панелям за один раз [Видно t=00:47–01:02].
3. **Выбор из списка ↔ сцена синхронизированы**: клик по имени подсвечивает панель на сцене [Видно t=01:22]. Удобно для деталей, которые не достать мышью (задняя стенка, цоколь).
4. **Скрытие фасадов одной кнопкой**, чтобы добраться до внутренних деталей [Видно t=00:09].
5. **Прозрачный вид с кромками красным** — быстрая визуальная проверка кромления всего корпуса [Видно t=02:09].
6. **Мини-чертёж детали прямо в инспекторе**: размеры, стороны L/W, кромки красным, направление волокна линиями. Вкладки L1–W2 работают как переключатели, щелчок ставит или снимает кромку [Видно t=02:24–02:30].
7. **Подчёркивание размеров по числу кромок** — компактная, привычная технологам нотация прямо в строке «Размеры» [Видно t=02:26].

## 8. Где можно сделать лучше

1. **При мультивыборе карточка показывает только последнюю деталь** (Түбі 568×560, кромка L1), хотя выбраны три с разными размерами и кромками. Нет счётчика «Выбрано: 3» и нет признака «разные значения» в полях [Видно t=00:53–00:59]. Субтитр «в списке тоже выделены три» не подтверждается: при выбранной детали список скрыт, видна только карточка.
2. **Удаление задней стенки не изменило цену** [Видно t=03:14–03:28], хотя субтитр обещает исключение из сметы. Либо итог не пересчитывается при удалении, либо ХДФ не входит в сумму. В RNM26 удаление детали обязано сразу менять смету, и это надо покрыть тестом.
3. **Смешанная локализация**: в списке «Боковина L / Дно / Задняя», в карточке «Бүйір L / Түбі / Артқы» (казахский). После восстановления имя меняется на «Задняя». Имя детали должно быть одним и стабильным; отображаемое имя — отдельное поле.
4. **Смена направления текстуры меняет порядок чисел в «Размеры», но не подписи L/W на чертеже.** После «по ширине» первым идёт 560, а L1 остаётся на стороне 815. Неясно, что такое «длина» для раскроя: размер вдоль волокна или длинная сторона. Нужно одно явное правило: «длина = вдоль волокна» и отдельно «стороны L/W привязаны к геометрии».
5. **У кромки нет толщины или типа** (0,4 / 1 / 2 мм, ПВХ / АБС) — только вкл/выкл. Без этого невозможна точная подрезка детали под кромку и смета кромки по типам. В RNM26 нужна толщина кромки на каждую сторону и вычет её из размера распила.
6. **Кнопки «+П» и «+Г» без подписей и подсказок**, в ролике не объяснены. Порядок четырёх полей «Скругление углов, R» не подписан (какой угол — какое поле).
7. **Удлинение без визуального указателя на чертеже**: размер 590 обновился, но не видно, какая сторона «наращена». Поле 30 мм в сером стиле, как и 0.
8. **Удалённая деталь показывает пустую область** вместо «серого» чертежа: размеры «—», геометрию не видно. Нельзя понять, что именно восстанавливаешь.
9. **Иконки панели инструментов без подписей** (часы, шапочка, карандаш, снежинка, человечек и т.д.), на видео нет подсказок при наведении.
10. **Выбор детали требует переключения режима**, а сразу после «Отменить» выделение сбрасывается: после отката групповой правки детали приходится выбирать заново.
