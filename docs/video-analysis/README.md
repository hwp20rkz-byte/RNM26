# Разбор видео QDesign: что показано и что из этого у нас

Источник — четыре скринкаста qdesign.kz, переданные файлами (≈32 мин). Звук не распознавался: модели распознавания речи недоступны из облачного окружения. Речь автора взята из вшитых субтитров (в v2 — казахский, с переводом). Каждый отрезок разобран по кадрам с шагом ≈3 с, спорные числа сверены по увеличенным кадрам.

## Порядок дальнейшей работы

1. **Стойки** (вертикальные перегородки и секции). Без них не собрать ни гардероб из v4, ни секционный шкаф.
2. **Библиотека типовых модулей** (тумба с ящиками, мойка, духовка, пенал, верхний шкаф, антресоль) — основа мастера.
3. **Комната и стены**, затем **этапный мастер** поверх них.
4. **Материалы по ролям** и прайс — как только будет прайс салона.
5. **Присадка** — вместе с экспортом на ЧПУ во второй версии.
