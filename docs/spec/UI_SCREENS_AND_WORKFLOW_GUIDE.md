# ПОЛНОЕ РУКОВОДСТВО ПО ИНСТРУМЕНТАМ И ЭКРАНАМ ВЕБ-КОНСТРУКТОРА
## Документация пользовательского интерфейса, инструментов и функционала для реализации в Claude Code

Данный документ содержит исчерпывающее описание каждого функционального модуля и инструмента конструктора на основе анализа видеодемонстраций системы создания параметрической мебели (Qdesign / Easy3D CAD).

---

## ИНСТРУМЕНТ 1: «ПЛАН КОМНАТЫ» (ROOM PLAN & WALL CONFIGURE TOOL)

### 1.1. Назначение и визуальное представление
Инструмент инициализирует рабочее 3D-пространство помещения. Позволяет задать габариты стен, высоту потолка, форму комнаты (прямоугольная, Г-образная, произвольная) и привязать координатную сетку.

### 1.2. Функциональные возможности
* **Выбор активной стены:** Клик по стене активирует режим редактирования ее размеров (длина, высота, толщина).
* **Сетка привязки (Snap Grid):** Шаг 10 мм, 50 мм, 100 мм с визуальной индикацией.
* **Синхронизация с 3D:** Изменение числового значения немедленно перестраивает геометрию стены и пола без перезагрузки сцены.

### 1.3. Входные параметры и свойства (Property Inspector)
| Поле ввода | Тип данных | Диапазон по умолчанию | Назначение |
|---|---|---|---|
| `Длина стены` | Integer (мм) | 1000 – 10000 (в демо: **3400**) | Габарит задней опорной стены |
| `Высота потолка` | Integer (мм) | 2000 – 4000 (в демо: **2950**) | Высота помещения, верхний лимит для шкафов |
| `Толщина стены` | Integer (мм) | 100 – 400 (стандарт: 150) | Толщина ограждающей конструкции |
| `Материал стен/пола` | ID текстуры | Белая краска / Ламинат | Визуализация окружения |

### 1.4. Логика для Claude Code
```typescript
class RoomManager {
  updateWall(wallId: string, length: number, height: number): void {
    const wallMesh = this.scene.getObjectByName(wallId) as THREE.Mesh;
    wallMesh.geometry.dispose();
    wallMesh.geometry = new THREE.BoxGeometry(length, height, 150);
    wallMesh.position.set(0, height / 2, -150 / 2);
    this.updateGrid(length, height);
  }
}
```

## ИНСТРУМЕНТ 2: «КОРПУС» (CARCASS & MODULE GENERATION TOOL)

### 2.1. Назначение и визуальное представление
Создает и конфигурирует параметрический мебельный модуль (тумбу, подвесной шкаф, антресоль, колонну). В отличие от статичных FBX/OBJ моделей, корпус генерируется процедурно из набора отдельных панелей (ЛДСП 16 мм или 18 мм).

### 2.2. Функциональные возможности
* **Добавление модуля:** Кнопка «Добавить модуль» размещает новый модуль в начале координат или над выбранным модулем («Добавить модуль сверху»).
* **Конфигурация крыши:**
  * `Накладная (Overlay)`: Крыша ложится сверху на торцы боковин (необходима для столешниц и нижних тумб, чтобы исключить затекание жидкостей и выдерживать нагрузку).
  * `Вкладная (Insert)`: Крыша зажата между боковинами (типовое решение для навесных верхних шкафов под потолок).
* **Конфигурация дна:**
  * `Накладное (Overlay)`: Несет нагрузку ящиков.
  * `Вкладное (Insert)`: Вкручивается между боковин.
  * `Накладное слева/справа (Overlay Left/Right)`: Боковина опускается до самого пола, а цоколь укорачивается на толщину боковины.
* **Задняя стенка:**
  * `ХДФ в паз (Groove)`: Задняя стенка утапливается в паз боковин (отступ 16 мм, глубина паза 8 мм), снаружи крепеж не виден.
  * `Накладная ХДФ`.
* **Цокольный узел:**
  * Высота цоколя (например, 50 мм, 100 мм или 0 для подвесных модулей).
  * Отступ от пола.

### 2.3. Входные параметры модуля
* `Имя модуля`: строка («Левая тумба», «Средний шкаф», «Подвесной стол»).
* `Ширина / Высота / Глубина`: числовые значения в мм (с точностью до 1 мм).
* `Тип крепежа`: Минификс (эксцентриковая стяжка для премиального скрытого монтажа) / Конфирмат (евровинт).

## ИНСТРУМЕНТ 3: «ПЕРЕМЕЩЕНИЕ И МАНИПУЛЯТОР (GIZMO)»

### 3.1. Назначение
Обеспечивает точное пространственное позиционирование модулей в комнате относительно стен и других шкафов.

### 3.2. Функциональные возможности
* **3D-Стрелки (Transform Controls):**
  * **Красная стрелка (Ось X):** Смещение влево/вправо.
  * **Зеленая стрелка (Ось Y):** Смещение вверх/вниз по высоте.
  * **Синяя стрелка (Ось Z):** Смещение вперед/назад (к задней стене).
* **Ограничение стен (Wall Collision Guard):** При перемещении модуль физически «упирается» в плоскость стены или соседнего модуля, блокируя пересечение геометрий.
* **Инструмент точного смещения (Shift Input):** Ввод точного расстояния в миллиметрах в поле оси (например, `+293 мм` для создания ниши под открытые полки).
* **Ручки масштабирования (Scale Handles):** Специальные манипуляторы на гранях для растягивания ширины/глубины модуля мышью с клавиатурным вводом точной цифры (например, ввод `400` или `293`).

## ИНСТРУМЕНТ 4: «КАТАЛОГ МАТЕРИАЛОВ И ИЗБРАННОЕ»

### 4.1. Назначение
Модальное окно выбора декоров плитных материалов (ЛДСП, МДФ, пластик, шпон) с поиском по артикулам и производителям.

### 4.2. Функционал
* **Поиск по артикулу:** Быстрый фильтр (например, `U708` — Egger Светло-серый, `H3303` — Дуб Галифакс).
* **Избранное (Starred Favorites):** Возможность пометить материал звездочкой для быстрого доступа из выпадающих списков инспектора.
* **Раздельное применение:**
  * Основной материал корпуса (боковины, дно, крыша).
  * Материал задней стенки (ХДФ белый, серый, венге).
  * Материал фасадов (матовые эмали, древесные поры, супермат).
  * Материал цокольной планки.

---

## ИНСТРУМЕНТ 5: «ПОЛКИ И РАЗДЕЛИТЕЛИ (СТОЙКИ)»

### 5.1. Назначение
Инструмент для внутреннего зонирования корпусов горизонтальными полками и вертикальными перегородками (стойками).

### 5.2. Функционал
* **Режим «Автодобавление» (Auto-Add):** Пользователь указывает количество полок (например, 1, 2, 4) и кликает мышью внутри целевой ячейки корпуса — система автоматически рассчитывает равные проемы.
* **Фиксация расстояния (Замок / Lock Gap):** Возможность зафиксировать конкретный проем (например, нижний проем ровно `800 мм` под нижнюю створку фасада) и нажать кнопку `Заменить` — полка перестраивается, а оставшееся пространство пересчитывается автоматически.
* **Вертикальные стойки (Dividers):** Разделение широких модулей (например, подвесного стола 3400 мм) на секции под выдвижные ящики с шагом 480 мм, 329 мм, 277 мм.

---

## ИНСТРУМЕНТ 6: «ВЫДВИЖНЫЕ ЯЩИКИ (DRAWERS)»

### 6.1. Назначение
Конструктор выдвижных систем: расчет короба, направляющих, зазоров и фасадов ящиков.

### 6.2. Функционал
* **Типы направляющих:** Телескопические шариковые полного выдвижения / Скрытый монтаж (Blum Tandem/Movento).
* **Проверка глубины (Depth Collision Guard):** Автоматическая проверка соответствия направляющей глубине стола (например, в стол глубиной 500 мм устанавливается телескоп 450 мм; направляющая 500 мм блокируется как не входящая в габарит).
* **Зазоры фасадов:** 
  * Верхний зазор: автоматические 3 мм до столешницы/крыши.
  * Нижний отступ: 25 мм для удобного зацепа при системе Push-to-Open (без ручек).
  * Межфасадный зазор: 3 мм.
* **Копирование параметров:** Изменение параметров одного ящика автоматически транслируется на последующие добавления в смежные секции.

---

## ИНСТРУМЕНТ 7: «ФАСАДЫ И ДВЕРИ (FACADES & HINGES)»

### 7.1. Назначение
Навешивание распашных створок на созданные секции корпуса.

### 7.2. Функционал
* **Интерактивный выбор контура (Boundary Picker):** Пользователь кликает по 4 границам будущей двери: `Левая боковина`, `Правая боковина`, `Верхняя полка/крыша`, `Нижняя полка/дно`. Фасад генерируется строго по выбранному периметру.
* **Сторона петель (Hinge Orientation):** Переключение открывания: «Левое» / «Правое». Позволяет развернуть петли от смежных стен или стола.
* **Ручки:** Выбор типа ручки: скоба, рейлинг, профиль или «Нет» (механизм Tip-On / Push-to-Open).

---

## ИНСТРУМЕНТ 8: «СТЕНОВЫЕ ПАНЕЛИ И ФРЕЗЕРОВКА»

### 8.1. Назначение
Создание настенных панелей (фартуков, реечных перегородок, декоративных щитов МДФ-шпон).

### 8.2. Функционал
* **Ориентация и координаты:** Фронтальное вертикальное размещение с точной привязкой координат X, Y, Z к торцам соседних пеналов и плоскости столешницы.
* **Библиотека фрезеровок (Milling Patterns):**
  * `Гладкая (Smooth)` — ровный шпон с вертикальным направлением волокон.
  * `Волна (Wave)` — радиусные вертикальные канавки с заданным шагом (имитация реечной панели).
  * `Рейка (Slats)`.

---

## ИНСТРУМЕНТ 9: «ОБЛАЧНЫЕ ПРОЕКТЫ И СИНХРОНИЗАЦИЯ»

### 9.1. Назначение
Управление жизненным циклом проекта: локальное кэширование и серверная синхронизация.

### 9.2. Функционал
* **Индикатор сохранения:** Предупреждение пользователю («Проект сохранен только в этом браузере»).
* **Загрузка в облако:** Сохранение структуры данных проекта (Project JSON) в Cloud Database (Firebase / PostgreSQL) под уникальным именем («Рабочая зона», «Кухня угловая»).

---

## ИНСТРУМЕНТ 10: «СМЕТА ПРОЕКТА И КОММЕРЧЕСКОЕ ПРЕДЛОЖЕНИЕ (КП)»

### 10.1. Назначение
Автоматический расчет себестоимости и формирование документов для клиента и цеха.

### 10.2. Функционал
* **Интерактивная таблица BOM (Bill of Materials):**
  * Листовые материалы (ЛДСП, МДФ, ХДФ) с расчетом полезной площади и коэффициентом обрезков (1.15).
  * Кромочные материалы (ПВХ 1 мм, 0.4 мм, 2 мм).
  * Фурнитура (направляющие, петли, стяжки минификс, конфирматы, навесы, ножки/цоколь).
  * Производственные операции (распил, кромление, ЧПУ-фрезеровка, присадка).
* **Собрать КП (Client Proposal View):**
  * Переключение режима в «Клиентский»: скрываются внутренние нормы расходов и себестоимость сырья, выводится укрупненный список гарнитура с итоговой стоимостью.
  * Экспорт в PDF с брендированной шапкой и цветной 3D-визуализацией.
