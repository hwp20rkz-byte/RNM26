# ТЕХНИЧЕСКОЕ ЗАДАНИЕ И ПОШАГОВЫЙ ПЛАН РАЗРАБОТКИ (ROADMAP ДЛЯ CLAUDE CODE)
## Проект: Parametric Web 3D Furniture & Interior CAD Constructor (Аналог Qdesign / Easy3D)

---

## 1. Введение и системный обзор

### 1.1. Назначение системы
Разработка промышленного высокопроизводительного браузерного 3D-конструктора корпусной мебели и интерьера. Конструктор позволяет:
1. Конфигурировать помещение (стены, проемы, высоты).
2. Процедурно генерировать параметрические корпуса (тумбы, шкафы, подвесные столы, стеновые панели) без предварительно созданных 3D-файлов.
3. Рассчитывать точные конструктивные сопряжения (накладные/вкладные детали, пазы под заднюю стенку ХДФ, подрезка цоколя боковинами).
4. Автоматически расставлять внутреннее наполнение (полки, вертикальные стойки/разделители, выдвижные ящики на телескопах) и крепежную фурнитуру (минификсы, конфирматы).
5. Назначать текстуры и карты рельефа (PBR: декоры ЛДСП, Egger, шпон, фрезеровки фасадов «волна/рейки»).
6. Мгновенно формировать производственную спецификацию (BOM), смету себестоимости и коммерческое предложение (КП) для клиента с генерацией PDF.
7. Экспортировать данные для ЧПУ-станков (CNC / CAM: присадка, раскрой).

* **Core 3D Engine:** `Three.js` (r160+), `three-bvh` (ускорение raycasting и детекции коллизий), `three-csg-ts` (булевы операции для пазов и вырезов).

* **State Management:** `Pinia` (для Vue) или `Zustand` (для React).

* **Документация и отчетность:** `pdfmake` / `jspdf` + `jspdf-autotable`.

## 3. Модель данных (Core Data Schema)

Конструктор работает не с сырыми 3D-файлами, а с реляционным деревом параметров:

```typescript
export interface ProjectState {
  id: string;
  name: string;
  room: RoomConfiguration;
  catalog: MaterialCatalog;
  modules: FurnitureModule[];
  wallPanels: WallPanel[];
  estimateSettings: PriceConfig;
}

export interface RoomConfiguration {
  width: number;    // мм (X)
  length: number;   // мм (Z)
  height: number;   // мм (Y, e.g. 2950)
  walls: WallDefinition[];
}

export interface FurnitureModule {
  id: string;
  name: string;      // e.g. "Левая тумба", "Подвесной стол"
  type: 'base_cabinet' | 'wall_cabinet' | 'table' | 'shelf_unit';
  transform: {
    x: number;
    y: number;
    z: number;
    rotationY: number;
  };
  dimensions: {
    width: number;
    height: number;
    depth: number;
  };
  plinth: {
    height: number;  // e.g. 50 мм
    elevation: number; // от пола, 0
  };
  construction: {
    topType: 'overlay' | 'insert' | 'none';    // Накладная или вкладная крыша
    bottomType: 'overlay' | 'insert' | 'overlay_left' | 'overlay_right'; // Дно
    backType: 'groove_hdf' | 'insert' | 'overlay' | 'none'; // Паз под ХДФ
    connectorType: 'minifix' | 'confirmat' | 'dowel'; // Крепеж
    leftSideToFloor: boolean;  // Боковина доходит до пола
    rightSideToFloor: boolean;
  };
  materials: {
    carcassMaterialId: string;
    backMaterialId: string;
    facadeMaterialId: string;
  };
  subdivisions: {
    shelves: ShelfElement[];
    dividers: DividerElement[];
    drawers: DrawerElement[];
    doors: DoorElement[];
  };
}

export interface WallPanel {
  id: string;
  width: number;
  height: number;
  thickness: number; // 16/18 мм
  position: { x: number; y: number; z: number };
  materialId: string;
  milling: 'smooth' | 'wave_slats' | 'fluted' | 'frame';
}
```

## 4. Пошаговый план разработки (Detailed Step-by-Step Roadmap)

### ФАЗА 1: Ядро рендеринга и геометрии (Week 1–2)
1. **Инициализация сцены Three.js:**
   * Настройка перспективы, OrbitControls, адаптивного ресайза, теней (Soft Shadow Maps), мягкого фонового и контурного освещения (AmbientLight + DirectionalLight + Contact Shadow Plane).
2. **Параметрическая комната:**
   * Создание замкнутого контура стен по размерам пользователя.
   * Наложение материалов (обои, штукатурка, плинтуса).
   * Двустороннее связывание с 2D-планом комнаты.
3. **Процедурная генерация плит (BoxGeometry + UV Mapping):**
   * Разработка модуля `createBoardMesh(width, height, thickness, material)`:
     * Автоматический расчет UV-координат для правильной ориентации волокон текстуры древесины.
     * Скругление ребер (Bevel / Normal beveling) для фотореализма стыков.

### ФАЗА 2: CAD-логика сопряжения корпусов и деталировка (Week 3–4)
1. **Конструктор деталей корпуса (Cabinet Assembler):**
   * Логика расчета геометрии деталей:
     * Если `topType === 'overlay'`: ширина крыши = габаритная ширина, глубина = глубина корпуса; боковины укорачиваются на толщину крыши (16 мм).
     * Если `topType === 'insert'`: ширина крыши = общая ширина минус (2 * толщина боковины).
     * Если боковина опускается до пола (`leftSideToFloor === true`), цоколь автоматически укорачивается на толщину боковины.
   * Фрезеровка паза под ХДФ (Back HDF Groove): отступ 16 мм от заднего края, глубина паза 8 мм, ширина 4 мм.
2. **Система манипуляций (Transform Gizmo & Snapping):**
   * Интеграция кастомных осей трансформации (Красная = X, Зеленая = Y, Синяя = Z).
   * Режим ввода точных смещений через инпуты (Shift offset, absolute coordinate).
   * Collision Wall Guard: ограничение движения `AABB.min.x >= wall.x`, `AABB.min.z >= wall.z` (объект не проходит сквозь стену).

### ФАЗА 3: Внутреннее наполнение и фурнитура (Week 5–6)
1. **Модуль полок и вертикальных стоек:**
   * Автоматическое деление проемов на N равных секций.
   * Фиксация высоты/ширины замком (Lock gap) с автоматическим вычислением остатка.
2. **Модуль выдвижных ящиков (Drawer Engine):**
   * Тип направляющих: скрытые Quadro / телескопические шариковые (длины: 300, 350, 400, 450, 500, 550 мм).
   * Проверка глубины: автоматический подбор длины телескопов (например, при глубине стола 500 мм выбирается телескоп 450 мм с зазором).
   * Процедурная генерация короба ящика (дно ХДФ/ЛДСП, царги, фасад).
   * Автоматический технологический зазор 3 мм сверху/снизу между фасадами.
3. **Модуль фасадов и дверей:**
   * Накладные и вкладные двери.
   * Переключение петель: левое / правое открывание.
   * Опции ручек: «Без ручки (Push-to-Open / Tip-On)», «Профиль Gola», врезные, накладные ручки.

### ФАЗА 4: Стеновые панели и фрезеровки (Week 7)
1. **Модуль декоративных панелей:**
   * Добавление независимых щитов МДФ/шпон.
   * Поддержка фрезеровок: «Волна» (вертикальные радиусные канавки), «Рейки», гладкий шпон.
   * Процедурные шейдеры нормалей для быстрой отрисовки фрезеровки без утяжеления полигональной сетки.

### ФАЗА 5: Смета, калькуляция и КП (Week 8)
1. **Движок деталировки (Bill of Materials):**
   * Рекурсивный обход сцены: извлечение списка всех деталей (длина, ширина, толщина, материал, кромка, отверстия).
2. **Финансовый калькулятор:**
   * Листовые материалы (м²), погонаж кромочной ленты (м.п.), штучная фурнитура (минификсы, конфирматы, петли, комплекты направляющих, цокольные опоры).
   * Наценка производства, сборка, монтаж.
3. **Генератор коммерческого предложения:**
   * Режим отображения для клиента (скрыта себестоимость деталей, отображается итоговая группа позиций, визуализация и опции).
   * Экспорт в PDF со встроенным цветным 3D-рендером изометрии.

## 5. Документация инструментов и экранов (Tooling & Screens)

Каждый инструмент конструктора строго документирован в отдельном руководстве `UI_SCREENS_AND_WORKFLOW_GUIDE.md`, включая:
1. **Инструмент «План комнаты» (Room Plan Tool)** — параметры габаритов и отрисовка стен.
2. **Инструмент «Корпус» (Carcass & Module Creation)** — габариты, сопряжение крыши/дна, цоколь.
3. **Инструмент «Перемещение и позиционирование» (Transform Gizmo & Wall Snap)** — оси координат, смещения.
4. **Инструмент «Каталог материалов» (Materials & Finishes)** — декоры Egger, шпон, избранное.
5. **Инструмент «Полки и стойки» (Shelving & Subdivisions)** — деление проемов, блокировка зазоров замком.
6. **Инструмент «Выдвижные ящики» (Drawers & Runners)** — подбор телескопов, зазоры Push-to-Open.
7. **Инструмент «Фасады и петли» (Facades, Doors & Hinges)** — выбор границ ячеек, сторона открывания.
8. **Инструмент «Стеновые панели и фрезеровка» (Wall Panels & Fluting/Milling)** — рельефы «Волна».
9. **Инструмент «Облачные проекты» (Cloud Sync & Storage)** — сохранение состояния JSON.
10. **Инструмент «Смета и Коммерческое предложение» (Estimates, Pricing & PDF Export)**.
