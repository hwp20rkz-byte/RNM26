# Видео для анализа

Сюда кладутся видеодемонстрации конструкторов-аналогов. Облачная сессия Claude Code **не может скачивать с YouTube, VK, Rutube и Google Drive**: сетевая политика окружения блокирует эти хосты. Поэтому видео нужно передать файлом.

Способы:

1. Закоммитить файл в эту папку. Лимит GitHub — 100 МБ на файл. Длинные ролики сожмите и порежьте:
   ```bash
   ffmpeg -i input.mp4 -vf scale=1280:-2 -c:v libx264 -crf 28 -an -f segment -segment_time 600 -reset_timestamps 1 part_%02d.mp4
   ```
   (`-an` убирает звук. Если в ролике важна речь автора, уберите этот флаг.)
2. Разрешить хост видео в настройках сети облачного окружения: Network access → Allowed domains. Тогда сработает прямая ссылка.
3. Задать `GEMINI_API_KEY` в переменных окружения. Хост `generativelanguage.googleapis.com` доступен: видео прогонит модель Gemini со звуком, но файл при этом уйдёт в Google.

Разбор запускается так: «разбери videos/part_01.mp4 скиллом analyze-cad-video». Результат появится в `docs/video-analysis/`.
