# ScreenPrint FabLab & MES/CRM — правила проекта

Проект живёт в папке `screenprint/` монорепозитория RNM26 (рядом — QazaqOSI, LSTK-конфигуратор и другие). Корневой `AGENTS.md` действует: перед любым кодом Next.js читать `node_modules/next/dist/docs/` этого пакета.

## Что это

Единая экосистема: параметрические станки для шелкографии из фанеры ЧПУ и алюминиевого профиля → 3D-конфигуратор с экспортом раскроя (SVG/DXF) и спецификации (BOM) → сайт с конструктором мерча и автовекторизацией → CRM/MES цеха → мобильное приложение (PWA, затем Capacitor).

Бизнес-логика: мастерская печати — ядро; станки строим для себя, потом продаём наборами; софт — рычаг, не продукт. Разработка идёт по гейтам (см. «Дорожная карта»).

## Структура

```
screenprint/
  src/domain/press/      параметрическая модель печатного станка (types, config, geometry, springs, bom)
  src/domain/exports/    nest (раскладка), svg, dxf, csv — чистые функции без DOM
  src/domain/<machine>/  натяжитель, экспокамера, промывка, сушка, профильная пила — по той же схеме
  src/app/               Next.js App Router: конфигуратор, сайт, CRM
  prisma/schema.prisma   данные: станки, заказы, макеты, цветоделение, рамы, техкарты, склад
  scripts/export.ts      CLI: раскрой + BOM + расчёт пружин → out/
  docs/                  инженерные описания, спецификации, раскрой (docs/cut), решения
```

Доменный слой не импортирует React, Next, Prisma и браузерные API. Всё, что считает размеры, деньги и нормы, живёт в `src/domain` и покрыто тестами Vitest.

## Стандарты проектирования узлов

- Единицы: миллиметры, килограммы, ньютоны, тенге. Система координат станка: X поперёк, Y вдоль печати (0 у переднего края, растёт назад), Z вверх от плиты основания.
- Фанера ФСФ: 18 мм несущие детали, 12 мм прижимные плиты и платены. Другие толщины — только с обоснованием в docs.
- Профиль: 4040 (паз 8) базовый, 4080 для столов шире 420 мм. 2020/2040 — только для лёгких рамок (экспокамера, крышки), не для несущих хребтов.
- Крепёж по нормативам: DIN 912 (винты с внутренним шестигранником), DIN 933, DIN 985 (самоконтрящиеся), DIN 9021 (увеличенные шайбы), DIN 580 (рым-болты), DIN 1480 (талрепы), забивные гайки M8 (отверстие 10 мм), Т-гайки паз 8.
- Шарниры только на подшипниках (608ZZ, 6200), вал 8 мм h6; болт в фанере как ось — запрещено.
- Правила отверстий: расстояние от края ≥ 2 диаметра; забивная гайка не ближе 20 мм к краю; подшипниковое гнездо в слое 18 мм глубиной 7 мм с остатком стенки ≥ 10 мм.
- Каждая деталь (`Part`) имеет `id` латиницей капсом, русское название, толщину, контур, отверстия (`through` / `pocket` / `insert-nut`), пазы, вырезы, карманы и примечания для сборщика.
- Уравновешивание рамы: расчёт в `springs.ts` (жёсткость по G·d⁴/8D³n), проверка внизу (0°) и вверху (70°), растяжение ≤ 90 % длины тела витков. Газлифт — альтернатива для рам тяжелее 4 кг.
- Экспорт: SVG в мм (`width="1525mm"`), цвета слоёв: чёрный рез, синий сквозные отверстия, красный карманы, зелёный гравировка. DXF R12 со слоями CUT/HOLE/POCKET/TEXT, `$INSUNITS = 4`. Компенсация фрезы — задача CAM, не наша.

## Стандарты спецификации (BOM)

Каждая строка: нормативное обозначение (DIN/ISO/ГОСТ/типоразмер), характеристика, количество, единица, цена от/до в тенге, поисковая строка RU и EN, где купить (Kaspi, Satu, AliExpress, строительные гипермаркеты, крепёжные магазины, склады фанеры, ЧПУ-подряд), примечание. Артикулы карточек маркетплейсов не являются обозначением: они живут недели. Цены — диапазоны [Предположение] до проверки по трём площадкам.

## Код

- TypeScript strict, `noUncheckedIndexedAccess`. Тесты рядом с кодом: `*.test.ts`. `npm test`, `npm run typecheck` обязаны проходить перед коммитом.
- Next.js App Router, серверные компоненты по умолчанию; 3D-сцены — клиентские компоненты (`"use client"`) на React Three Fiber + drei; анимация техпроцессов — GSAP timeline со step-контролем.
- Стили: Tailwind v4, токены в `src/app/tokens.css` (шрифты, шкала, HSL-палитра, 8-пунктовая сетка) создаются до компонентов; сырые hex в компонентах — ошибка ревью. Правила `.claude/rules/website-quality.md` монорепозитория действуют.
- Данные: Prisma + SQLite из коробки (`DATABASE_URL="file:./dev.db"`), переключение на PostgreSQL сменой provider. JSON хранится строками в полях `*Json`.
- Язык интерфейса и документации — русский; идентификаторы кода — английский.
- Метки уверенности в документации: [Точно] — проверено, [Вероятно] — сильный вывод, [Предположение] — оценка.
