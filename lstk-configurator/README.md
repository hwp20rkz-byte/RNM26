# LSTK 3D Configurator · Планировщик

3D-планировщик построек из ЛСТК (профиль C89 линии Golden Integrity): библиотека из 17 типовых
и своих построек, этажность и цоколь, планировка, утепление по климату 35 городов РК, отделка,
электрика, сантехника и вентиляция, фундамент, себестоимость с электроэнергией по тарифу,
доставка с весом и габаритами. Интерфейс на русском, казахском и китайском.
Next.js 16 (App Router, static export) · React Three Fiber · Zustand · Tailwind v4 · Vitest.

Адрес после деплоя: `https://hwp20rkz-byte.github.io/RNM26/lstk-configurator/`

```bash
cd lstk-configurator
npm install
npm run dev        # http://localhost:3100
npm test           # 314 тестов: домен, расчёт, узлы, смета, выгрузки, альбом, словари
npm run typecheck
npm run build      # статический экспорт в out/
```

## Что умеет

### Планировщик построек (вкладки)

- **Каталог** — беседка, зона барбекю, мангальная зона, дачный домик, дом 1 и 2 этажа, барнхаус,
  A-фрейм, баня, навесы на 1/2 авто, гаражи на 1/2 авто, хозблок, курятник, птичник, мастерская,
  своя постройка. Пиктограмма каждой карточки рисуется из параметров изделия.
- **Форма** — длина, пролёт, 1–2 этажа с высотой каждого, назначение (жилой / сезонный / баня /
  без отопления), фундамент (винтовые сваи, лента, плита, без фундамента) и цоколь, кровля
  двускатная или односкатная (уклон, свес, высота низкой опоры, решётка), каждая сторона этажа —
  стена с проёмами, полуоткрытая (парапет) или открытая (стойки и обвязка).
- **Планировка** — план этажа в масштабе, поперечные и продольные перегородки с дверями, назначение
  помещений кликом, экспликация. Перегородки генерируются как стеновые панели P{этаж}.{n}.
- **Утепление** — город (35 городов РК: t холодной пятидневки, отопительный период, средняя
  температура, глубина промерзания, снег), ГСОП и требуемое R по элементам, состав стены /
  чердачного перекрытия / пола со схемой слоёв в масштабе, подбор толщины сплошного наружного
  слоя с учётом мостиков холода стальных стоек, проверка риска конденсата, мощность отопления
  и тепло за сезон в тенге по тарифу.
- **Отделка** — фасад, кровля (с цветами RAL), цоколь, стены и потолки, мокрые зоны, парилка,
  полы; площади с отходом, стоимость материала и работы, масса.
- **Инженерия** — розетки, свет, автоматы, УЗО, кабель 1,5/2,5/6, втулки в отверстия стоек,
  установленная и расчётная мощность, точки водоразбора, трубы, канализация, воздухообмен,
  вентиляторы; для курятника и птичника — площадь, насесты, гнёзда, вентиляция, выгул по поголовью.
- **Смета** — сталь и крепёж, электроэнергия производства (линия 14,5 кВт по КП × часы работы ×
  тариф, по умолчанию 48 ₸/кВт·ч), труд, утеплитель, мембраны, OSB, отделка, окна и двери,
  инженерия, фундамент, монтаж, доставка, накладные, наценка.
- **Доставка** — габариты постройки, общий вес и объём груза по составу, самый длинный элемент,
  поставка панелями или комплектом деталей, сравнение машин (Газель — фура), число рейсов,
  стоимость по расстоянию, негабарит и необходимость манипулятора.
- **3D** — отделка в выбранных цветах и фактурах, окна со стеклом, двери, ворота, цоколь,
  фундамент, полы помещений по назначению, мебель и окружение (машины, стол и лавки, мангал,
  печь с трубой, кухня, верстак, гнёзда, насесты, вольер, лестница), размеры, разрез-план по этажам
  с подписями помещений, ракурсы камеры, снимок PNG, четыре режима освещения.

- **Расчёт** — нагрузки по городу (снег по EN 1991-1-3 с μ по уклону, ветер, постоянные, полезная на перекрытие),
  сочетания 1,35G + 1,5S/Q, проверка поясов и решётки ферм, ферм перекрытия, стоек (сжатие + ветер),
  перемычек по EN 1993-1-3 (эффективная ширина, кривая b), подбор толщины C89 из линейки линии.
  Без сертификата на G550 сталь считается по 350 МПа. Сейсмика ≥ 7 баллов — предупреждение, не расчёт.
- **Узлы** — угол из трёх стоек, Т-примыкание парой доборных стоек, коробчатые стойки у проёмов > 1200 мм,
  перемычки: одиночная ≤ 600 мм, короб 600–900 мм, ферма-перемычка ≥ 900 мм, фермы-прогоны над открытыми
  сторонами, крестовые связи из ленты, анкеры M12 через ≤ 1200 мм, hold-down, скобы ферм; чертежи узлов.
- **Смета** — 17 разделов от геодезической разбивки и основания до проектирования и надзора, материалы и работы
  раздельно, накладные, непредвиденные, сметная прибыль, НДС 12%. Выгрузка: Excel с живыми формулами
  (смета, раскрой, узлы, расчёт), PDF, Word, CSV, HTML, JSON.
- **Чертежи** — альбом A3 по ГОСТ Р 21.101-2020, 21.501-2018, 21.502-2016: общие данные, планы этажей с осями,
  размерными цепочками и экспликацией, фасады с отметками, разрез, схемы фундаментов, ферм и панелей, чертёж
  каждой панели и фермы с позициями, спецификация металлопроката, узлы. PDF через печать или HTML.
- **Презентация** — модель на весь экран с медленным вращением, ключевые цифры, итог расчёта, разделы сметы,
  док управления камерой и светом (компоненты React Bits: CountUp, BlurText, SpotlightCard, AnimatedList,
  Dock, StatusMark; лицензия в `src/features/bits`).
- **Второй этаж** наследует оси окон, перегородки и стояки первого.

База знаний по нормам и каталогам ЛСТК: [docs/lstk-knowledge-base.md](docs/lstk-knowledge-base.md).

### Детали каркаса
- **Стеновая панель**: обвязка, стойки по сетке, крайние стойки полками внутрь, проёмы со стойками
  проёма, перемычкой, подоконным ригелем и короткими стойками, ригели на середине высоты.
  Обжатие торцов стоек и димплы во всех узлах.
- **Ферма**: треугольная, трапециевидная, с параллельными поясами, односкатная. Проверка неизменяемости и усилия
  от расчётной нагрузки, которую вводит пользователь.
- **Профиль**: C/U/Z/Ω, пробивка, свойства сечения.
- **3D**: обшивка (кровля, стены с проёмами, фронтоны), схема сборки (разнесённый вид по слоям),
  клик по элементу (длина реза, масса, операции), три режима освещения.
- **Спецификация**: профиль, сборки (одинаковые фермы — одна марка), раскрой с марками деталей,
  крепёж, сталь с отходом, стоимость, площади кровли и стен, доборные элементы.
- **Файлы**: спецификация CSV, раскрой CSV (нейтральный формат), DXF-чертежи по маркам сборок,
  проект JSON (сохранить и открыть), КП на печать или в PDF со снимком 3D.
  Проект автоматически сохраняется в браузере.
- **Проверка изготовимости**: каждая деталь сверяется с профилем, толщиной и инструментами линии.

## Что реализовано

**Профили** (`domain/profiles`). Сечение строится как средняя линия с гибами радиуса
`r + t/2`, затем смещается на ±t/2. Отсюда точная площадь, центр тяжести, Ix/Iy, ширина
штрипса (развёртка) и масса с цинком. Тест сверяет площадь с t × развёртка для всего
каталога. Каталог — типовые размеры, **не ТУ конкретного производителя**.

**Операции** (`domain/members/punching.ts`): сервисные отверстия, димплы/болтовые отверстия
в узлах, шахматные термопрорези. `validateFeatures` ловит выход за элемент, заход на гиб и
пересечение отверстий между собой. Например, термопрорези по умолчанию пересекаются с
сервисными отверстиями, и это ошибка раскладки, а не геометрии.

**Фермы** (`domain/trusses`): треугольные (Финк, Хау, Пратт), трапециевидные (Хау, Пратт),
с параллельными поясами (Пратт, Хау, Уоррен).
- Расчётная модель: узлы и стержни. `checkDeterminacy` решает систему метода узлов: ферма
  должна быть неизменяемой и статически определимой. Тест прогоняет каждую комбинацию
  формы, решётки и числа панелей.
- `solveTruss` даёт усилия в стержнях; сверено с ручным расчётом.
- Производственная модель: прямой пояс катается одним куском, длиннее заготовки — стык в
  узле. Свес продолжает верхний пояс. Пары димплов ставятся в каждом узле.

**3D** (`render/`). `createCProfileMesh`, `createUProfileMesh`, `createZProfileMesh`,
`createHatProfileMesh`, `createTrussMesh`, `createMembersGroup`.
- Быстрый режим: одна геометрия единичной длины на профиль и `InstancedMesh`. Сцена в тысячи
  элементов стоит столько вызовов отрисовки, сколько в ней разных профилей.
- Детальный режим: стенка — пластина с настоящими отверстиями, полки и гибы — отдельные
  полосы. Тест сверяет удалённый объём стали с площадью отверстий.

**Линия** (`domain/machines`). Golden Integrity LGS C89: каждое значение из коммерческого
предложения хранится со ссылкой на страницу, неизвестное — как `null` с пояснением. Каталог C89
строится из этих данных. `memberOnMachine` проверяет профиль, толщину и операции, а также
сверяет развёртку со штрипсом из КП. Сводка данных: [docs/golden-integrity-c89.md](docs/golden-integrity-c89.md).

## Чего здесь нет и почему

- **Климат 32 из 35 городов — инженерная оценка.** Астана, Алматы и Шымкент сверены с СП РК
  2.04-01-2017 по документам проекта; остальные интерполированы по соседним станциям и
  помечены в интерфейсе. Перед рабочим проектом таблицу надо сверить с СП РК.
- **Цены отделки, инженерии, фундамента и перевозки — ориентиры 2026 г. без НДС.** Ставки
  (тариф, труд, сталь, наценка) вводит пользователь; каталожные цены меняются в `domain/*`.
- **Инженерия и фундамент — оценка объёмов, не проект.** Нормы — типовые; без изысканий грунта
  фундамент не назначается.
- **Тексты проверок и экспорт CSV/DXF — на русском** при любом языке интерфейса.
- **Стены длиннее 6 м** в доставке считаются разрезанными на панели, но в модели остаются одной
  сборкой.

- **Каркас Howick-типа из одного профиля C89.** Стойки и обвязка из одного сечения, торцы стоек
  обжимаются. Перемычка над проёмом — один C89 плашмя, без усиления. Для широких проёмов и ворот
  проектировщик должен назначить перемычку-ферму или спаренный профиль. Стойки навеса — два C89 спиной
  к спине. Это заготовки для расчёта, а не готовое решение.
- **Длины — по осевым линиям.** Для станка нужна деталировка узлов: зазоры вложения, торцевые
  подрезки, `lip-cut`/`flange-cut`. Она зависит от конкретной линии. Без неё CSV для станка
  выдаст детали, которые не соберутся.
- **Расчёт упрощённый.** Не проверяются искажение сечения (distortional), изгибно-крутильная форма, смятие
  стенки, узлы, прогибы, сейсмика. Это предварительный подбор, а не расчёт проектировщика.
- **Снег и ветер по городам — ориентиры.** Районы взяты по зонам, город-район не сверен с картами
  НТП РК 01-01-3.1(4.1)-2017; значения помечены и редактируются.
- **Альбом — проектная заготовка** без подписей; юридической силы как проект не имеет.
- **«Инженерный штамп» в PDF.** Программа может выдать предварительный подбор с пометкой
  «требует проверки», но не подпись проектировщика.
- **Формат CNC.** DSTV/NC1 — для линий горячекатаного проката. Профилегибочные линии ЛСТК
  (Howick, FrameCAD, Scottsdale и др.) используют свои форматы. Экспорт делается под
  конкретную линию.
- **Route Handlers и Python-сервис** не работают при статическом экспорте на GitHub Pages и
  потребуют отдельного хостинга.
