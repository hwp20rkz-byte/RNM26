# База знаний ЛСТК для конфигуратора (Казахстан)

Каркас: один профиль C89×41×11, t = 0,75–1,2 мм, сталь G550, линия Golden Integrity (пробивка
в стиле Howick: димпл, обжатие торца, подрезка отгиба, вырез стенки, сервисное отверстие,
болтовое отверстие, фаска). Соединения на саморезах через димплы, платформенный каркас,
1–2 этажа, стропильные фермы с шагом 600 мм.

Документ собран 2026-10-08 по открытым источникам. Тексты норм не копировались, всё изложено
своими словами. Числа, которые не удалось подтвердить первоисточником или надёжным вторичным
источником, помечены **[не проверено]**. Решения, которые не взяты из норм, а приняты как
обычная практика, помечены **[инженерная практика]**. Перед выпуском рабочей документации
каждое правило проверяет аттестованный в РК инженер.

Условные обозначения уровня проверки:

- **✔** номер и название документа подтверждены поиском (официальный реестр, издатель или
  профильная база вроде NormaCS);
- **≈** подтверждено вторичным источником (отчёт ICC-ES, вуз, производитель ПО), текст нормы
  не открывался;
- **[не проверено]** взято из общих знаний, источник в сети не найден.

## 2. Правила конструирования

Американские значения переведены в мм. Для каждого правила указан источник. Где у нас нет
текста нормы, правило помечено.

### 2.1 Угол наружных стен

- По IRC R603.4 и рисунку R603.4 угловые стойки и верхние направляющие выполняются по
  типовому узлу, верхние направляющие внахлёст соединяются 4 саморезами №8 (≈ 4,2 мм) ≈
  (CRC 2025 R603.4, [gocodebook](https://gocodebook.com/us/california/california-residential-code/wall-construction/openings-headers-and-alternate-systems/cold-formed-steel-studs-headers-and-splicing)).
  Сколько стоек показано на рисунке, **[не проверено]**.
- Практика Howick/FRAMECAD: в углу ставят 2 стойки (концевая стойка одной панели и концевая
  стойка другой, стенки под 90°) и третью стойку или Г-образную накладку, когда нужна опора
  для листа обшивки или ГКЛ изнутри **[инженерная практика]**.
- Для конфигуратора:
  - угол «2 стойки + опора для ГКЛ из отрезка профиля» по умолчанию;
  - угол «3 стойки», когда по углу сходятся связи-ленты или стоит анкер hold-down.

### 2.2 Примыкание перегородки к стене (Т-узел)

- Узел должен давать опору листу ГКЛ с обеих сторон примыкания. Варианты:
  - две стойки наружной стены по бокам примыкания с шагом ≈ 100–150 мм;
  - одна стойка плюс горизонтальные бобышки (noggings) между стойками, к которым крепится
    крайняя стойка перегородки, через ≤ 600 мм по высоте;
  - **[инженерная практика]**, норм с числами не найдено.

### 2.3 Проёмы: стойки проёма (king / jack)

- По IRC R603.7 и табл. R603.7(1) число полновысотных (king) и подпорных (jack) стоек зависит
  от ширины проёма и шага стоек. Стойки проёма того же сечения и толщины, что и рядовые ✔
  (текст R603.7 по CRC). Пример из вторичного источника: проём 3,2–3,66 м при шаге 610 мм
  требует по 2 king и 2 jack с каждой стороны, при шаге 406 мм по 3 ≈
  ([GBA](https://www.greenbuildingadvisor.com/question/number-of-king-studs-for-an-11-opening)).
  Значения для узких проёмов **[не проверено]**.
- Перемычка крепится к king-стойкам по табл. R603.7(2). В коробчатых перемычках половина
  саморезов идёт в перемычку, половина в стойку через уголок или отрезок направляющей ✔.
- Полки и отгибы стоек и перемычек подрезать нельзя (IRC R603.2.x) ≈. Исключение —
  заводские подрезки отгиба под соединения Howick-типа, заложенные в расчёт.

### 2.4 Перемычки (headers / lintels)

Типы, которые реально собрать из одного C89:

| Тип | Состав | Примечание |
|---|---|---|
| Коробчатая (box) | 2 C89, полками внутрь, через направляющие | AISI считает несущую способность как сумму двух швеллеров; испытания показывают запас 34–152 % ([Sci. Rep. 2024](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11237124/)) |
| Спаренная (back-to-back) | 2 C89 стенками вместе | Стенки взаимно усиливают друг друга против смятия; несущая способность принимается как 2× одиночного ≈ (NAHB, 1997, [huduser.gov](https://huduser.gov/portal/node/147)) |
| L-перемычка | Уголок поверх верхней направляющей | Из C89 не прокатывается; методика по AISI S240 ≈ |
| Решётчатая (truss header) | Пояса и раскосы из C89 на димплах | Наш основной вариант для проёмов > 1,2–1,5 м **[инженерная практика]** |

Подбор: изгиб плюс срез и смятие стенки на опоре (EN 1993-1-3 / AISI S100). Для 1-го этажа
двухэтажного дома нагрузка складывается из грузовой полосы кровли и перекрытия. Табличные
пролёты есть в IRC/S230 (табл. R603.6(x)) **[не проверено]**, но они для американских
профилей 350S162 и др., на C89 не переносятся.

### 2.5 Подоконник, короткие стойки (cripples)

- Подоконник: одна направляющая или C89 стенкой вниз. Над проёмом и под ним стоят короткие
  стойки с шагом рядовых стоек (600 мм) по той же разметке ✔ (IRC: короткие стойки того же
  сечения, что и рядовые).
- При ширине проёма > 1200 мм подоконник делают двойным (коробчатым), чтобы он держал
  ветровую нагрузку от окна **[инженерная практика]**.

### 2.6 Бобышки и распорки (noggings / blocking / bridging)

- Назначение: раскрепление стоек из плоскости (если обшивка не учитывается в расчёте), опора
  для кромок листов и навесного оборудования.
- Подход AISI S240: либо «sheathing-braced design» (обшивка раскрепляет стойку в точках
  крепления саморезами), либо стальное раскрепление (лента + распорки, или клипса + профиль)
  периодически по высоте ≈ ([buildsteel.org о FRAMECAD](https://buildsteel.org/framing-products/connections/framecad-offers-strategies-for-optimizing-bracing-and-anchoring-in-steel-framing-projects/)).
- Практика Howick/NASH: ряд бобышек через ≤ 1200–1350 мм по высоте; при высоте стены
  2,4–2,8 м один ряд посередине **[не проверено по NASH Part 2]**.

### 2.7 Связи и восприятие горизонтальных нагрузок

- Варианты (FRAMECAD): K-раскосы из профиля (жёсткие, мешают утеплителю), крест из стальной
  ленты (лёгкий, дешёвый, требует натяжения), диафрагма из обшивки (лучшая прочность и
  пластичность, больше материала) ≈
  ([FRAMECAD blog](https://framecad.com/blog/bracing-the-future-bracing-and-hold-down-brackets-for-steel-framing)).
- Связи нужны не в каждой стене, их расставляют по расчёту ≈ (там же).
- Узел ленты: лента крепится к угловой стойке и направляющей через косынку. Стойки у концов
  связевой панели воспринимают растяжение и сжатие и должны иметь анкер против отрыва
  (hold-down). В сейсмике лента должна течь раньше, чем срежутся саморезы (принцип
  ёмкостного проектирования по AISI S400) **[не проверено]**.
- Ленту ставят с натяжением ≈ (FRAMECAD).

### 2.8 Анкеровка к фундаменту, hold-down

- IRC R603.3.1: стены анкеруются к фундаменту по табл. R603.3.1. Анкеры стоят не дальше
  305 мм (12″) от углов и концов нижней направляющей (у дверных проёмов). Заделка ≥ 178 мм
  в бетон ≈ ([ICC proposal RB168](https://www.iccsafe.org/cs/codes/Documents/2007-08cycle/ProposedChanges/V2_RB168-174.pdf)).
  Диаметр ≥ 12,7 мм (½″) и шаг 1829 мм (6 ft) ≈ (рисунок 780 CMR Massachusetts; аналог
  для дерева IRC R403.1.6). Табличных значений для стали **[не проверено]**.
- JGJ 227-2011: анкер против отрыва у основания стеновой панели каждого этажа. Двухгаечные
  анкеры заметно повышают несущую способность стены ≈ ([zjujournals 2019](https://www.zjujournals.com/eng/EN/10.3785/j.issn.1008-973X.2019.04.014)).
- Hold-down ставится у каждого конца связевой (сдвиговой) панели и в углах здания
  **[инженерная практика]**, усилие считается по расчёту (FRAMECAD Steelwise считает
  hold-down для ферм и стен) ≈.

### 2.9 Стык направляющих

- Стойки и другие несущие элементы стыковать нельзя без расчёта. Направляющие стыкуются по
  типовому узлу (IRC/CRC R603.3.5, рисунок) ✔ (текст пункта по CRC 2025).
- Типовой узел: вкладыш из C-профиля длиной ≥ 150 мм (6″) по 4 самореза №8 с каждой стороны
  стыка **[не проверено]**. Стык располагается под стойкой или рядом с ней, не в проёме
  **[инженерная практика]**.
- При Howick-подобной пробивке стык делают через обжатый (swage) конец, вставленный в
  соседний элемент **[инженерная практика]**.

### 2.10 Стойка–направляющая, саморезы, кромки

- Стойка к направляющей: по 1 саморезу №8 в каждую полку с каждой стороны, итого 2 на конец
  стойки (IRC табл. R603.3.1 / R603.3.2) **[не проверено]**.
- Саморезы по ASTM C1513, не меньше №8 для крепления обшивки по IRC R505.2.5, R603.2.5,
  R804.2.5 ≈ ([ICC-ES ESR-4706](https://icc-es.org/wp-content/uploads/report-directory/ESR-4706.pdf)).
- AISI S100 J4 (IBC 2021/2024): саморез считается полностью работающим, если шаг ≥ 3d и
  расстояние до кромки ≥ 1,5d. При шаге между 2d и 3d несущая способность на срез снижается
  на 20 % ≈ ([ICC-ES ESR-4849](https://icc-es.org/wp-content/uploads/report-directory/ESR-4849.pdf)).
  Для d = 4,2 мм: шаг ≥ 13 мм, до кромки ≥ 6,5 мм.
- В IBC 2015/2018 до кромки требовалось ≥ 3d, кроме случая, когда кромка параллельна усилию
  (тогда 1,5d) ≈.
- Выход самореза за последний слой ≥ 3 витков ≈ (требование отдельных ICC-ES, не общее).
- Расчёт среза и вырыва самореза по EN 1993-1-3 (табл. 8.2) **[не проверено номер таблицы]**.

### 2.11 Димпловые соединения (Howick-тип)

- Димпл — коническое продавливание вокруг отверстия под саморез: головка утапливается, листы
  обшивки ложатся ровно, отверстия двух деталей центрируются при сборке
  **[инженерная практика]**. Конфигурация узла в ПО Tekla Howick Tools: подрезка отгиба
  стойки, обжатие (swage) горизонтального элемента, димплы ≈
  ([Tekla](https://support.tekla.com/help/tekla-structures/not-version-specific/ext_howicktools)).
- Линия Golden Integrity: штампы dimple hole, chamfer cut, web notch, lip cut, service hole,
  swage, shear, bolt hole ✔ ([КП JCX/Golden Integrity](https://www.buildersshow.com/assets/docs/ibs/logos/ExhibitorProductLit_207208_JCX-offerforC89LGSframingmachine-Celina.pdf)).
  Размеры штампов в КП не указаны, см. `docs/golden-integrity-c89.md`.
- Узел «стенка в стенку» внутри C89 возможен только для обжатого конца (swage), иначе
  наружная ширина 89 мм не входит между полками. Каждая пара деталей в узле соединяется не
  меньше чем 2 саморезами (лучше 2 на полку) **[инженерная практика]**.
- Альтернатива: заклёпки Howick Rivet Connector, они прочнее саморезов и пластичнее болтов ≈
  ([Waikato thesis](https://researchcommons.waikato.ac.nz/bitstreams/ebb79b1e-cf0a-461f-b717-41fd5f8a9e57/download)).

### 2.12 Сервисные отверстия

- IRC R603.2.6 отсылает к AISI S230 A4.5. Отверстия вне этих условий усиливают (A4.6) или
  закрывают накладкой (A4.7) ✔ (цитата R603.2.6 на форуме ICC).
- Предельные размеры по S230 A4.5 в часто цитируемом виде: ширина ≤ 38 мм (1½″), длина
  ≤ 102 мм (4″), шаг ≥ 610 мм (24″), от торца ≥ 254 мм (10″). Эти числа **[не проверено]**.
- Другие источники: ширина отверстия ≤ ½ высоты стенки и ≤ 63 мм, длина ≤ 114 мм (CFSEI
  Tech Note G500, Intertek CCRR-0224). Для изгибаемых элементов AISI S100 требует шаг
  отверстий ≥ 457 мм (18″) и центрирование по высоте стенки ≈
  ([buildsteel.org](https://buildsteel.org/?p=3344), [STRUCTURE](https://www.structuremag.org/wp-content/uploads/C-JustFAQs-CFS-Mar121.pdf)).
- Для C89 (стенка 89 мм): ≤ 38 мм по высоте, по центру стенки.
- Отверстия не ставят ближе 254 мм к опоре, торцу или сосредоточенной нагрузке, и не в зоне
  димплов узла **[инженерная практика по S230]**.

### 2.13 Фермы: конёк, пята, опирание

- Фермы из C89 на димплах: пояса и раскосы стенка к стенке, раскосы обжаты. В каждом узле
  ≥ 2 самореза. Пятовой узел (верхний пояс с нижним) — ≥ 4 самореза или болт по расчёту
  **[инженерная практика]**. FRAMECAD Steelwise считает усилия отрыва ферм ≈.
- Конёк: оба верхних пояса соединяются через накладку или стойку фермы **[инженерная практика]**.
- Ферма к стене: уголок или клипса на каждой ферме, саморезы в стенку фермы и в верхнюю
  направляющую. Число саморезов по усилию отрыва от ветра **[инженерная практика]**.
- Ферма по возможности опирается над стойкой (in-line framing, принцип S230). Если ферма
  попадает между стойками, верхняя направляющая проверяется на изгиб или ставится
  распределительная балка ≈ (S230 описывает «in-line framing» как условие применимости).
- Фермы перекрытия опираются на верхнюю направляющую стены с выравниванием по стойкам. Под
  сосредоточенными нагрузками ставятся рёбра жёсткости против смятия стенки
  **[инженерная практика]**.

### 3.1 Материал

| Сталь линии | G550, t = 0,75–1,2 мм | КП Golden Integrity ✔ |
| G550 (AS 1397) | fy ≈ fu ≈ 550 МПа; для тонкой G550 AS/NZS 4600 понижает расчётные fy/fu (t < 0,9 мм) | понижающий коэффициент **[не проверено]** |

| Расчётная толщина | t_cor = t_nom − толщина покрытия (Z275 ≈ 0,04 мм на две стороны) | EN 1993-1-3 §3.2.4 **[не проверено номер]** |

Если сертификата на G550 нет, считать как S350GD (fyb = 350 МПа)
**[инженерная практика, консервативно]**.

### 3.2 Частные коэффициенты

- EN 1993-1-3: γM0 = 1,00, γM1 = 1,00, γM2 = 1,25 (рекомендованные; так в НП Кипра и
  Финляндии). В проекте НП к редакции 2024 γM1 = 1,05 ≈ ([Cyprus NA](https://moi.gov.cy/MOI/moiup/moi.nsf/all/05FE06BB537676ACC22585A100430DF8/$file/Cyprus%20National%20Annex%20EN%201993-1-3%20-%20corrected%2015%2011%202019.pdf)).
  Значения НП РК **[не проверено]**.
- EN 1990 (рекомендованные): γG = 1,35, γQ = 1,5, ψ0: перекрытие кат. A 0,7, снег 0,5, ветер
  0,6 **[не проверено по НП РК]**.

### 3.3 Сечение: эффективная ширина и DSM

- EN 1993-1-3 / EN 1993-1-5: сжатые пластины заменяют эффективной шириной (метод Кармана).
  Отгиб 11 мм проверяется как краевой элемент жёсткости с понижением толщины из-за
  искажения формы сечения (distortional buckling) ≈
  ([БНТУ, метод эффективной ширины](https://rep.bntu.by/handle/data/118486)).
- AISI S100: альтернатива — метод прямой прочности (DSM): местная, искажающая и общая потеря
  устойчивости считаются по упругим критическим нагрузкам (CUFSM). Тот же метод добавлен в
  новый GB 50018 (прил. C) ≈.
- Классификация сечений EN 1993-1-1 для холодногнутых швеллеров неточна, используем
  эффективные характеристики ≈ (ResearchGate, 270163158).
- Для конфигуратора: эффективные характеристики C89×41×11 для t = 0,75 / 0,95 / 1,0 / 1,15 /
  1,2 мм заранее посчитать (CUFSM или Dlubal/RFEM) и хранить таблицей. В рантайме их не
  вычислять **[инженерная практика]**.

### 3.4 Стойки: сжатие и изгиб с ветром

- Потеря устойчивости: изгибная по сильной оси (расчётная длина = высота этажа),
  изгибно-крутильная и по слабой оси (раскреплена обшивкой или бобышками).
- Раскрепление обшивкой (sheathing-braced design) допускается AISI S240 при обшивке с обеих
  сторон и заданном шаге крепежа ≈. EN 1993-1-3 §10.1 допускает раскрепление элементов
  профлистом или обшивкой **[не проверено номер]**. Если обшивка с одной стороны или ГКЛ,
  надёжнее ряд стальных бобышек **[инженерная практика]**.
- Внецентренное сжатие: N/Nb,Rd + M/Mb,Rd ≤ 1 (упрощённая форма EN 1993-1-3 §6.2.5 /
  AISI S100 H1.2) **[не проверено номер]**. Ветровой момент для наружных стен:
  M = w·s·H²/8 (w — давление, s — шаг стоек 0,6 м, H — высота).
- Смятие стенки на опоре (web crippling): проверяется на опорах перемычек и ферм.

### 3.5 Предельные прогибы

| Элемент | Предел | Источник |
|---|---|---|
| Наружная стена с хрупкой отделкой (штукатурка, плитка) | L/240 | IBC табл. 1604.3 ≈ |
| Наружная стена с гибкой отделкой (сайдинг, профлист) | L/120 | IBC табл. 1604.3 ≈ |
| Перекрытие, полезная нагрузка / полная | L/360 / L/240 | IBC табл. 1604.3 ≈ |
| Кровля без потолка | L/180 | IBC табл. 1604.3 ≈ |
| Балки и фермы, пролёт 6 м (РФ) | l/200 | СП 20.13330.2016 табл. Д.1 **[не проверено после Изм. 3]** |
| Ветровой прогиб облицовки | можно брать 0,7 × нагрузки на облицовку | IBC, сноска к 1604.3 ≈ |

Для КЗ (EN 1990, прил. A1.4) пределы задаёт НП или заказчик **[не проверено]**. Принимаем по
умолчанию: стойки L/240, фермы и перемычки L/250 (полная) / L/300 (переменная)
**[инженерная практика]**.

### 3.6 Снег (EN 1991-1-3 / СП РК EN 1991-1-3)

- s = μi · Ce · Ct · sk ✔ (лекция ЕКТУ; EN 1991-1-3 (5.1)).
- Ce: продуваемая местность 0,8; обычная 1,0; защищённая 1,2 (рекомендованные) ≈. Ct = 1,0
  для обычной кровли.
- μ1 для двускатной и односкатной кровли ≈ ([finesoftware](https://finesoftware.eu/help/finec/en/snow-load-01/)):

| Уклон α | μ1 |
|---|---|
| 0° ≤ α ≤ 30° | 0,8 |
| 30° < α < 60° | 0,8·(60 − α)/30 |
| α ≥ 60° | 0 |

- Если снегозадержатели не дают снегу сходить, μ1 = 0,8 при любом уклоне ≈.
- Для двускатной кровли кроме равномерного случая проверяются несимметричные: на одном скате
  0,5μ1 **[по EN 1991-1-3 рис. 5.3]**.
- Высокогорье (Алтай, Северный Тянь-Шань, Жетысуский Алатау): sk зависит от высоты площадки
  над уровнем моря, по формулам НП ≈ (лекция ЕКТУ).

### 3.7 Ветер (EN 1991-1-4)

- vb = cdir · cseason · vb,0; qb = ½ · ρ · vb², ρ = 1,25 кг/м³; qp(z) = ce(z) · qb
  **[общеизвестные формулы EN 1991-1-4; НП РК не открывалось]**.
- Наружное давление на стены: зона D (наветренная) ≈ +0,7…+0,8, зона E (подветренная)
  ≈ −0,3…−0,5, зоны A/B у торцов до −1,2 (cpe,10) **[не проверено по НП РК]**.
- Районирование РК по базовой скорости (повторяемость 1 раз в 50 лет) построено Казгидрометом
  по наблюдениям 1971–2011 гг. ≈ ([журнал Казгидромета, 2015](https://journal.kazhydromet.kz/kazgidro/article/download/507/529/6882)).
  Значения vb,0 по районам и городам **[не проверено]**.

## 6. Правила для генератора

Каждое правило — параметр по умолчанию, который пользователь может переопределить. Тег в
конце строки — источник. Числа без нормы помечены `[инженерная практика]`. Размеры в мм.

### 6.1 Общие

1. Шаг стоек стен — 600 мм от начала стены. Разметка стоек, ферм и балок перекрытия
   совпадает по осям (in-line framing), допуск смещения ≤ 20 мм. — AISI S230 (условие
   применимости in-line) ≈; допуск `[инженерная практика]`.
2. Все элементы — C89×41×11; t по умолчанию: стойки 1-го этажа двухэтажного дома 1,0–1,2;
   прочие стойки 0,95; фермы 0,95; перемычки и hold-down стойки 1,2. —
   `[инженерная практика]`, подтверждается расчётом.
3. Если t < 0,9 мм и сертификата на G550 нет — fy = 350 МПа. — EN 10346 S350GD ≈;
   `[инженерная практика]`.
4. Термопрорезей нет (линия их не делает). — КП Golden Integrity ✔.

### 6.2 Стены

5. Каждая панель: нижняя и верхняя направляющая на всю длину, концевые стойки на обоих концах.
   — IRC R603 ✔ (общий принцип).
6. Наружный угол: 2 стойки + опорный профиль для ГКЛ; если в углу связь или hold-down — 3
   стойки. — `[инженерная практика]`; верхние направляющие внахлёст на углу, 4 самореза. —
   IRC R603.4 ≈.
7. Т-примыкание перегородки: 2 стойки наружной стены с зазором 100–150 мм, либо 1 стойка +
   бобышки через ≤ 600 мм по высоте. — `[инженерная практика]`.
8. Проём ≤ 1200 мм: по 1 king + 1 jack с каждой стороны, перемычка коробчатая из 2 C89. —
   `[инженерная практика]` (принцип IRC R603.7).
9. Проём 1200–2400 мм: по 2 king + 1 jack, перемычка коробчатая или решётчатая. —
   `[инженерная практика]`.
10. Проём > 2400 мм: по 2 king + 2 jack, решётчатая перемычка высотой ≥ 300 мм, обязательный
    расчёт. Проём 3,2–3,66 м при шаге 600: не меньше 2 king + 2 jack. — IRC табл. R603.7(1) ≈.
11. Над перемычкой и под подоконником короткие стойки по общей разметке 600. — IRC R603.7 ✔.
12. Подоконник: проём ≤ 1200 — одиночная направляющая; > 1200 — двойной (коробчатый). —
    `[инженерная практика]`.
13. Бобышки: 1 ряд при высоте стены ≤ 2800, 2 ряда при > 2800 (шаг ≤ 1350); дополнительно на
    стыках листов обшивки, если они горизонтальные. — `[инженерная практика]`, NASH
    **[не проверено]**.
14. Стыки направляющих только над стойкой ±100 мм, вкладыш ≥ 150 мм, по 4 самореза с каждой
    стороны; стойки не стыкуются. — IRC R603.3.5 ✔ (запрет), размеры **[не проверено]**.
15. Стойка — направляющая: по 1 саморезу в каждую полку, всего 2 на торец стойки. — IRC
    R603.3.x **[не проверено]**.

### 6.3 Связи и анкеры

16. Связь — крест из ленты 40×1,0 (или 50×1,0) в каждой торцевой секции каждой наружной
    стены и не реже чем через 6 м по длине; угол ленты 30–60° к горизонтали; лента
    натягивается; косынки на концах. — `[инженерная практика]`; натяжение и выбор по
    расчёту — FRAMECAD ≈.
17. Если стена обшита ОСП/ЦСП ≥ 9 мм с саморезами по контуру ≤ 150 и в поле ≤ 300, разрешить
    «диафрагма вместо ленты» при подтверждении расчётом. — `[инженерная практика]`, AISI
    S240 (сдвиговые стены) ≈.
18. Hold-down на обоих концах каждой связевой панели и в каждом наружном углу. В двухэтажном
    доме — стяжка между стойками 1-го и 2-го этажа (сквозь перекрытие) на тех же осях. —
    JGJ 227-2011 ≈; `[инженерная практика]`.
19. Анкеры нижней направляющей к фундаменту: Ø ≥ 12 мм, шаг ≤ 1200 (при сейсмике ≥ 7 баллов ≤
    800), ≤ 300 от углов, концов направляющей и краёв дверных проёмов; не меньше 2 на
    отдельный участок направляющей; заделка ≥ 180 мм. — IRC R603.3.1 ≈ (≤ 305 от
    углов/концов, заделка 178); шаг 1200 строже IRC (1829) `[инженерная практика]`.

### 6.4 Крепёж и пробивка

20. Саморез по умолчанию — 4,2 мм (№8) по металлу, сверлоконечный; шаг ≥ 3d = 13; до кромки
    ≥ 1,5d = 6,5. Генератор не ставит димпл ближе 10 к кромке полки или торцу. — AISI S100 J4
    ≈; запас 10 мм `[инженерная практика]`.
21. В каждом узле из двух деталей ≥ 2 самореза (димпла); в пятовом узле фермы ≥ 4; в узлах
    перемычки с king-стойкой половина в перемычку, половина в стойку через уголок. — IRC
    R603.7 ✔ (распределение); количество `[инженерная практика]`.
22. Сервисные отверстия: только в стойках и элементах ферм, по центру стенки, высота ≤ 38,
    длина ≤ 102 (или Ø ≤ 32 при круглом штампе), шаг ≥ 600, ≥ 250 от торцов и опор, ≥ 150
    от димплов узла. Ряды по умолчанию на высоте 300 и 1100 от пола. — AISI S230 A4.5
    **[не проверено]**; отметки `[инженерная практика]`.
23. Подрезка полок и отгибов только заводская (lip cut / web notch под узел). Ручные вырезы
    запрещены. — IRC R603.2.x ≈.

### 6.5 Фермы и перекрытие

24. Фермы с шагом 600 по осям стоек; каждая ферма крепится к верхней направляющей уголком на
    ≥ 4 самореза (2 в ферму, 2 в направляющую). Отрыв проверяется по ветру. —
    `[инженерная практика]`.
25. Снег на кровлю: μ1 = 0,8 при α ≤ 30°; 0,8·(60 − α)/30 при 30° < α < 60°; 0 при α ≥ 60°;
    при снегозадержателях 0,8. Плюс несимметричный случай 0,5μ1 на одном скате. — EN 1991-1-3
    ≈ / СП РК EN 1991-1-3 ✔ (формула).
26. sk вводит пользователь (кПа) с подсказкой «район по карте НП к СП РК EN 1991-1-3: 0,8 /
    1,2 / 1,5 / 1,8 / 2,4 / 3,2 / 4,0 / 4,8 / > 5,6». — Казгидромет 2014 ≈.
27. Прогибы: стойки L/240 (ветер), фермы и перемычки L/250 от полной и L/300 от переменной,
    балки и фермы перекрытия L/360 от полезной. — IBC 1604.3 ≈; `[инженерная практика]`.
28. Фермы перекрытия опираются на верхнюю направляющую над стойкой; при смещении > 20 мм от
    стойки генератор добавляет распределительную балку или ребро. — S230 in-line ≈;
    `[инженерная практика]`.
29. Если пролёт фермы > 12 м, уклон < 10° или sk > 2,4 кПа, выводится предупреждение
    «нужен индивидуальный расчёт». — `[инженерная практика]`.

### 6.6 Расчётные коэффициенты по умолчанию

30. γM0 = γM1 = 1,0; γM2 = 1,25; γG = 1,35; γQ = 1,5; ψ0: снег 0,5, ветер 0,6, перекрытие 0,7.
    Все значения настраиваются под НП РК. — EN 1993-1-3 / EN 1990 рекомендованные ≈; НП РК
    **[не проверено]**.
